Ядро Linux для чайников

Что это, зачем нужно и почему все о нём говорят.

Что такое ядро

Ядро (kernel) — это посредник между программами и железом. Когда ты открываешь файл, играешь музыку или подключаешь флешку — все эти операции проходят через ядро. Оно управляет:

  • Процессором (какая программа сколько времени работает)
  • Памятью (какая программа где лежит)
  • Дисками (чтение и запись файлов)
  • Сетью (передача данных)
  • Устройствами (клавиатура, мышь, USB, GPU)

Ядро и дистрибутив — разные вещи

Часто путают. Ядро — это одно. Дистрибутив — это ядро + утилиты + оболочка + приложения. Ubuntu, Fedora, Arch — все они используют одно и то же ядро Linux, только разные версии.

Версии ядра

Формат: 6.8.0-31-generic. Расшифровка:

  • 6 — major (главная версия)
  • 8 — minor (обновления с новыми фичами)
  • 0 — patch (баг-фиксы)
  • 31 — сборка
  • generic — тип (для Ubuntu это стандартное ядро)

Типы ядер

  • Generic — стандартное, для большинства
  • Low-latency — для аудио (Ubuntu Studio)
  • RT (Real-Time) — для промышленных систем
  • Hardened — усиленная безопасность
  • LTS — долгосрочная поддержка
  • Zen — для игр и десктопа (CachyOS)

Как посмотреть версию

uname -r

Или красиво:

uname -a

Обновление ядра

Обычно приходит вместе с системными обновлениями. Проверить:

sudo apt update && sudo apt upgrade

Список установленных ядер:

dpkg --list | grep linux-image

Удалить старое:

sudo apt autoremove

Модули ядра

Ядро состоит из модулей — кусочков, которые можно включать и выключать на лету. Например, драйвер Wi-Fi или поддержка NTFS. Посмотреть загруженные:

lsmod

Загрузить модуль:

sudo modprobe nvidia

Параметры ядра передаются при загрузке через GRUB. Например nomodeset — если чёрный экран.

Зачем вообще знать про ядро

  • Понимать, почему обновление ядра иногда ломает драйверы
  • Знать, как откатиться на старое ядро из меню GRUB
  • Понимать, зачем нужны LTS-ядра
  • Выбирать правильное ядро под задачи (low-latency для аудио, RT для производств)

Сборка своего ядра

Можно, но не нужно 99% пользователей. Gentoo-фанаты собирают своё ядро для оптимизации. Это часы работы и много чтения. Если не понимаешь зачем — не начинай.
