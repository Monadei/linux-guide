Сетевые команды Linux

Смотреть, диагностировать, настраивать.

Интерфейсы и IP

ip a              # все интерфейсы и адреса
ip -c a           # цветной вывод
ip link           # только линки
ip route          # таблица маршрутов
ip neigh          # ARP-таблица

Старое, но работает:

ifconfig
route -n

Пинг и проверка связи

ping ya.ru
ping -c 4 8.8.8.8
ping -i 0.5 ya.ru  # интервал 0.5 сек
ping6 ya.ru        # IPv6

DNS

nslookup ya.ru
dig ya.ru
dig ya.ru +short
host ya.ru
resolvectl status  # systemd-resolved

Порты и соединения

ss -tulpn        # все слушающие порты
ss -tunap        # активные соединения
ss -s            # статистика
lsof -i :80      # что занимает порт 80
netstat -tulpn   # старое

Расшифровка флагов ss:

  • -t TCP, -u UDP
  • -l listening, -a all
  • -p показать процессы
  • -n не резолвить имена

Скачивание

curl -O https://example.com/file.zip
curl -L -o file.zip URL  # с редиректами
wget https://example.com/file.zip
wget -c URL              # продолжить загрузку
curl ifconfig.me         # свой внешний IP
curl wttr.in             # погода

SSH и передача файлов

ssh user@server
scp file user@server:/path/
scp user@server:/path/file .
rsync -avh --progress source/ user@server:/dest/

Трассировка

traceroute ya.ru
tracepath ya.ru       # без root
mtr ya.ru             # постоянная трассировка

Wi-Fi

nmcli device wifi list
nmcli device wifi connect "SSID" password "пароль"
nmcli connection show
nmcli connection up "имя"

Старое:

iwconfig
iw dev

Firewall

sudo ufw status
sudo ufw enable
sudo ufw allow 22
sudo ufw deny 23
sudo ufw delete allow 22

Firewalld (Fedora, RHEL):

sudo firewall-cmd --state
sudo firewall-cmd --list-all
sudo firewall-cmd --add-port=8080/tcp --permanent
sudo firewall-cmd --reload

Диагностика

# Проверить, работает ли сайт
curl -I https://ya.ru

# Проверить, отвечает ли порт
nc -zv ya.ru 443

# Проверить DNS
dig +trace ya.ru

# Показать трафик
sudo iftop
sudo nethogs

# Захват пакетов
sudo tcpdump -i any port 80

Настройка сети вручную

Через netplan (Ubuntu):

sudo nano /etc/netplan/01-network-manager-all.yaml
network:
  version: 2
  ethernets:
    enp3s0:
      dhcp4: true

Применить:

sudo netplan apply
