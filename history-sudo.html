История одной команды: sudo

Как маленькая программа изменила подход к администрированию.

До sudo

В 1970-х в Unix был только su (substitute user). Чтобы выполнить команду от имени root, ты:

  1. Вводил su
  2. Вводил пароль root
  3. Выполнял команду
  4. Выходил через exit

Проблема: для этого нужно было знать пароль root. А если работают несколько админов — пароль у всех один. И никакого лога, кто что делал.

1980: появление sudo

Боб Кокран и Клифф Спенсер из SUNY/Buffalo разработали sudo — «superuser do». Идея: пользователь вводит свой пароль, а не root'а. Система проверяет по файлу /etc/sudoers, что ему разрешено, и выполняет команду от имени root.

1994: переход в open source

Тодд Миллер (Todd C. Miller) взял проект и поддерживает его до сих пор — уже 30+ лет. sudo стала стандартом де-факто в Unix-подобных системах.

Что даёт sudo

  • Свой пароль, а не root'а — каждый админ знает только свой
  • Гибкая настройка — кому что разрешено, в /etc/sudoers
  • Логи — видно, кто и что выполнял
  • Таймаут — после первого ввода пароль запоминается на 15 минут
  • Ограничения — можно разрешить только конкретные команды

Как это выглядит

sudo apt install firefox

Что происходит:

  1. sudo проверяет, есть ли пользователь в /etc/sudoers
  2. Спрашивает пароль (свой)
  3. Проверяет права
  4. Выполняет команду от root
  5. Записывает в лог

Конфигурация

Файл /etc/sudoers. Редактировать только через visudo — он проверяет синтаксис и не даст сохранить сломанный файл.

sudo visudo

Пример: разрешить пользователю monadei команды apt без пароля:

monadei ALL=(ALL) NOPASSWD: /usr/bin/apt

Альтернативы

  • doas — минималистичная альтернатива из OpenBSD, ~500 строк кода против 100 000 у sudo
  • pkexec — используется в GNOME и KDE для графических запросов пароля
  • run0 — новая утилита systemd (2024), задумана как замена sudo

Пасхалка

Если ввести:

sudo make me a sandwich

sudo ответит:

Okay.

А если написать make me a sandwich без sudo — ответит What? Make it yourself.. Это наследие XKCD комикса №149.

В России

sudo включён в большинство дистрибутивов. В Ubuntu пользователь, созданный при установке, автоматически получает права sudo. В Debian — надо добавить в группу sudo:

usermod -aG sudo monadei
