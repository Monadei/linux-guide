Как установить Linux

Пошаговое руководство. От загрузки ISO до первой настройки системы.

0. Что понадобится

  • Флешка 8+ ГБ (все данные будут уничтожены)
  • Скачанный ISO-образ
  • 30–60 минут времени
  • Резервная копия важных данных (обязательно!)

1. Запись ISO на флешку

На Ubuntu/Debian/Mint:

sudo dd if=~/Downloads/ubuntu.iso of=/dev/sdX bs=4M status=progress oflag=sync

Где /dev/sdX — твоя флешка (проверь через lsblk!). Не перепутай с жёстким диском.

На Windows: Rufus или balenaEtcher. На macOS: balenaEtcher.

2. UEFI или BIOS — что выбрать

Современные ПК (после 2012) — UEFI. Старые — BIOS. Обычно UEFI включён по умолчанию.

  • Secure Boot — выключи, если установщик не грузится. Ubuntu и Fedora поддерживают его, некоторые другие — нет.
  • Fast Boot — выключи, чтобы флешка была видна.
  • RAID/RST — если стоит Intel RST, переключи на AHCI, иначе Linux не увидит диск.

3. Загрузка с флешки

Перезагрузи ПК. Во время POST нажми клавишу Boot Menu:

  • ASUS: F8 или Esc
  • Gigabyte: F12
  • MSI: F11
  • Lenovo: F12
  • HP: F9
  • Dell: F12
  • Apple: зажми Option

Выбери USB-накопитель. Загрузится Live-система или установщик.

4. Разметка диска

Это самый ответственный момент. Варианты:

  • Стереть весь диск — установщик сам разобьёт. Простой вариант, если Linux будет единственной ОС.
  • Рядом с Windows — установщик уменьшит раздел Windows и создаст свои. Безопасно при наличии свободного места.
  • Вручную — для опытных. Нужны минимум: /boot/efi (512 МБ, FAT32), / (30+ ГБ), /home (по вкусу), swap (по RAM).

Внимание: «Стереть диск» уничтожит ВСЁ. Сделай бэкап заранее.

5. Dual-boot с Windows

  1. В Windows: Управление дисками → сжать том → освободи 40+ ГБ
  2. Отключи Fast Startup: Панель управления → Электропитание → Действия кнопок питания → Отключить быстрый запуск
  3. Загрузись с флешки, выбери «Установить рядом с Windows»
  4. GRUB автоматически найдёт Windows и добавит в меню

6. Шифрование LUKS

Рекомендуется для ноутбуков. Установщик Ubuntu и Fedora предлагают галочку «Зашифровать диск» — просто включи. Пароль придётся вводить при каждой загрузке.

Минус: если забудешь пароль — данные не восстановить.

7. Первый запуск

  • Обнови систему: sudo apt update && sudo apt upgrade (Ubuntu/Debian)
  • Установи драйверы: sudo ubuntu-drivers autoinstall (для NVIDIA)
  • Настрой тачпад, яркость, звук через «Параметры»
  • Установи браузер, мессенджеры, кодеки из центра приложений

8. Что дальше

  • Изучи горячие клавиши своего DE
  • Настрой бэкапы: Timeshift для системы, rsync/Borg для данных
  • Установи timeshift, gparted, htop, neofetch
  • Почитай словарь терминов, если что-то непонятно

9. Если что-то пошло не так

  • Не грузится система — загрузись с флешки в Live-режиме и восстанови GRUB
  • Чёрный экран после установки — попробуй nomodeset в параметрах ядра
  • Не работает Wi-Fi — подключи по кабелю, установи драйверы
  • Пропала Windows — GRUB её найдёт: sudo update-grub
  • Не хватает места — перераспредели разделы через GParted с Live USB
