Обзор рабочих столов

Каждый DE — отдельная философия. Разбираем подробно.

GNOME

Философия: минимализм и фокус на задачах. Меньше интерфейса — больше дела.

Плюсы: современный дизайн, отличная поддержка Wayland, огромная экосистема расширений, отличные жесты тачпада.

Минусы: мало настроек из коробки, приходится ставить расширения для базовых вещей, требователен к ресурсам.

Где стоит: Ubuntu, Fedora, Debian, Pop!_OS (COSMIC — форк).

Кому: тем, кто любит «чистый» интерфейс и готов допиливать напильником.

KDE Plasma

Философия: максимальная гибкость и контроль. Настроить можно всё.

Плюсы: гибкость как у конструктора, отличная поддержка Wayland (с 6.0), лёгкий по сравнению с GNOME, огромное количество встроенных приложений.

Минусы: перегруженность настроек (иногда сложно найти нужное), исторически нестабилен (сейчас лучше).

Где стоит: Kubuntu, KDE Neon, openSUSE, KDE Linux.

Кому: тем, кто хочет контролировать каждую деталь, мигрантам с Windows.

Xfce

Философия: лёгкость, стабильность, классика.

Плюсы: очень лёгкий, стабильный как скала, работает на старом железе, знакомый интерфейс (панель + меню).

Минусы: не самый современный вид, не всё поддерживает Wayland, меньше «вау-эффекта».

Где стоит: Xubuntu, MX Linux, Manjaro Xfce.

Кому: владельцам старого железа, тем, кому нужна классика и стабильность.

Cinnamon

Философия: GNOME 2 «как надо». Классический интерфейс без компромиссов.

Плюсы: знакомый интерфейс как в Windows 7, из коробки всё что нужно, отличная интеграция с Linux Mint.

Минусы: только в Linux Mint и производных, не так активно развивается как GNOME/KDE.

Где стоит: Linux Mint, LMDE, Fedora Cinnamon Spin.

Кому: мигрантам с Windows, тем, кто любит классику.

MATE

Философия: продолжение GNOME 2. Классика без изменений.

Плюсы: очень стабилен, лёгкий, знакомый интерфейс, живёт активным сообществом.

Минусы: визуально устарел, некоторые приложения не интегрируются хорошо.

Где стоит: Ubuntu MATE, Linux Mint MATE.

Кому: любителям GNOME 2, владельцам старого железа.

LXQt

Философия: максимально лёгкий. Минимум ресурсов — максимум пользы.

Плюсы: очень лёгкий (работает на 512 МБ RAM), стабильный, модульный.

Минусы: не самый красивый, меньше возможностей настройки.

Где стоит: Lubuntu.

Кому: старым ноутбукам, нетбукам, встраиваемым системам.

Budgie

Философия: современный минимализм с классической логикой.

Плюсы: красивый, интуитивный, отличается от GNOME/KDE.

Минусы: меньше сообщества, ограниченная кастомизация.

Где стоит: Ubuntu Budgie, Solus.

Кому: тем, кто хочет что-то нетипичное, но удобное.

Pantheon

Философия: дизайн прежде всего. Красота и простота в каждой детали.

Плюсы: один из самых красивых DE, знакомый macOS-подобный интерфейс, отличные фирменные приложения.

Минусы: только elementary OS, ограниченная кастомизация, медленнее развивается.

Где стоит: elementary OS.

Кому: дизайнерам, любителям macOS-подобного интерфейса.

COSMIC

Философия: новый DE от System76, написан на Rust.

Плюсы: тайлирование из коробки, современный, быстрый, активно развивается.

Минусы: ещё молодой, не всё готово, мало документации.

Где стоит: Pop!_OS.

Кому: энтузиастам, тем кто хочет попробовать новое.

Тайловые WM

Не полноценные DE, а оконные менеджеры. Окна делят экран, управление — с клавиатуры.

  • i3 — классика, настраивается вручную, X11
  • Sway — i3 для Wayland
  • Hyprland — современный, с анимациями, Wayland
  • bspwm — бинарное дерево, минимализм
  • dwm — минималистичный, настройка через C-код
  • Openbox — стековый WM, классика

Кому: разработчикам, тем, кто много работает с терминалом, любителям ricing.

Как выбрать

  • Новичку → GNOME (Ubuntu) или Cinnamon (Mint)
  • Со старым ПК → Xfce или LXQt
  • С древним ПК → Moksha, IceWM
  • Любителю настраивать → KDE Plasma
  • Дизайнеру → Pantheon (elementary)
  • Мигранту с Windows → Cinnamon или Zorin
  • Разработчику → i3, Sway, Hyprland
