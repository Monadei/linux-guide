Виртуализация в Linux

Запускать другие ОС внутри своей.

KVM + QEMU — встроено в ядро

Самый быстрый вариант, работает на уровне ядра. Проверить поддержку:

egrep -c '(vmx|svm)' /proc/cpuinfo

Если число больше 0 — можно использовать.

Установка:

sudo apt install qemu-kvm libvirt-daemon-system virt-manager
sudo usermod -aG libvirt,kvm $USER

Перелогинься. Дальше — virt-manager для графического интерфейса.

GNOME Boxes

Простой GUI для KVM. Идеален для быстрого тестирования:

sudo apt install gnome-boxes

Создать виртуалку — три клика. Работает быстрее VirtualBox.

VirtualBox

Кроссплатформенный, много документации.

sudo apt install virtualbox virtualbox-ext-pack

Для USB 2.0/3.0 нужен Extension Pack. Добавить себя в группу:

sudo usermod -aG vboxusers $USER

VMware Workstation Player

Бесплатен для личного использования. Скачивается с сайта Broadcom.

sudo apt install build-essential
# скачал .bundle, потом:
sudo sh VMware-Player-*.bundle

Плюсы: лучшая производительность 3D, снимки. Минусы: проприетарный.

QEMU без KVM

Только программная эмуляция, медленно. Нужно для ARM на x86 или наоборот:

qemu-system-aarch64 -M virt -cpu cortex-a72 -m 2G ...

Контейнеры vs виртуалки

  • Виртуалка — своё ядро, полная изоляция, тяжело
  • Контейнер — общее ядро, легче, быстрее, но менее изолирован

Контейнеры: Docker, Podman, LXC/LXD.

Что выбрать

  • Быстро потестить дистрибутив — GNOME Boxes
  • Полноценная виртуалка на каждый день — virt-manager + KVM
  • Windows-программы — VirtualBox или Wine/Bottles
  • Серверная виртуализация — Proxmox VE

Проброс GPU

Возможно, но сложно. Требует:

  • Две GPU (одна для хоста, одна для гостя)
  • Поддержка IOMMU (включить в BIOS/UEFI)
  • Правильная настройка VFIO

Многие делают так для игровых виртуалок с Windows.
