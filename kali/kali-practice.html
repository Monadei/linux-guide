Где практиковаться в ИБ

TryHackMe, Hack The Box, PortSwigger — что выбрать и в каком порядке.

Обзор С чего начать Инструменты Практика Защита Linux

Зачем практика

Можно прочитать 10 книг по пентесту и не уметь ничего. Только практика на реальных (легальных) площадках даёт навык. Без неё теория — мёртвый груз.

Первые 3 месяца я смотрел видео и думал «я всё понимаю». Потом зашёл на первую HTB-машину и понял, что не знаю ничего. Это был полезный урок.

TryHackMe — для начала

tryhackme.com — самый дружелюбный вариант для новичков. Комнаты с теорией + практикой, пошаговые подсказки, если застрял.

Что проходить

  1. Pre Security — базовая сеть, Linux, веб
  2. Introduction to Cyber Security — обзор специальностей
  3. Jr Penetration Tester — путь пентестера
  4. Complete Beginner — общий курс для старта

Плюсы

  • Всё в браузере — не нужно настраивать окружение
  • Пошаговые подсказки — не бросаешь на полпути
  • Бесплатные комнаты (часть), премиум ~$14/мес
  • Хорошо для понимания основ

Минусы

  • Слишком «по рельсам» — не развивает самостоятельность
  • После прохождения — сложно переходить на реальные машины

Hack The Box — для серьёзных

hackthebox.com — площадка для тех, кто уже понял базу. Реальные машины, никаких подсказок. Каждая — мини-проект на несколько часов.

С чего начать

  1. Starting Point — специальные лёгкие машины с гайдами
  2. Потом — Easy машины
  3. Потом Medium — там начинается боль
  4. Hard и Insane — для опытных

Как работать с машиной

  1. Подключаешься к VPN (OpenVPN)
  2. Получаешь IP машины
  3. Сканируешь (nmap)
  4. Ищешь уязвимости
  5. Получаешь user.txt (первый флаг)
  6. Повышаешь привилегии
  7. Получаешь root.txt (второй флаг)

Что делать, если застрял

  • Не смотри write-up сразу
  • Дай себе 2–3 часа. Пробуй разные подходы
  • Если совсем никак — смотри подсказку (не решение)
  • Если и это не помогло — смотри write-up IppSec на YouTube
  • Главное — понять, что ты упустил
Первая HTB-машина заняла у меня 6 часов. Я не получил флаг, но понял, как работает SMB. Через 2 недели эта же машина заняла 40 минут. Прогресс есть, просто он не сразу виден.

Другие площадки

VulnHub

vulnhub.com — бесплатные виртуалки для скачивания. Ставишь локально, ломаешь. Минус — устаревшие, меньше подсказок.

PortSwigger Web Security Academy

portswigger.net/web-security — бесплатные лаборатории по веб-уязвимостям. Лучший ресурс для веб-пентеста. Всё в браузере.

PentesterLab

pentesterlab.com — фокус на веб, много упражнений на конкретные уязвимости.

OverTheWire

overthewire.org — старые добрые wargames. Bandit — отличный старт для командной строки.

PicoCTF

picoctf.org — CTF для новичков. Обычно весной проходит соревнование, но задания остаются.

Локальные лаборатории

  • DVWA — уязвимое веб-приложение для практики
  • OWASP Juice Shop — современное уязвимое приложение
  • Metasploitable 2/3 — намеренно уязвимые VM
  • VulnHub — сотни VM для скачивания

Как построить план

Месяц 1–2: основы

  • TryHackMe: Pre Security + Complete Beginner
  • OverTheWire: Bandit (все уровни)
  • Linux: команды, файлы, права, процессы
  • Сеть: OSI, TCP/IP, DNS, HTTP

Месяц 3–4: веб

  • PortSwigger Academy: все лаборатории по OWASP Top 10
  • TryHackMe: Jr Penetration Tester путь
  • DVWA + Juice Shop локально
  • Burp Suite — уверенное использование

Месяц 5–6: HTB

  • HTB: Starting Point (все машины)
  • HTB: 10+ Easy-машин
  • Смотреть write-up'ы IppSec после решения
  • Начать вести свой блокнот с техниками

Месяц 7–12: углубление

  • HTB: Medium-машины
  • Active Directory: HTB Pro Labs
  • Специализация: веб, сеть, облака, IoT
  • Подготовка к сертификации (eJPT, OSCP)
Не гонись за скоростью. У меня ушло 8 месяцев до первой уверенной Medium-машины. У кого-то получается за 4, у кого-то за год. У каждого свой темп. Главное — не бросать.
Все практики — только на легальных площадках. Не пытайся «потренироваться» на чужих сайтах, Wi-Fi соседа или рабочей сети. Это статья, и это не шутка.
