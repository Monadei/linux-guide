Инструменты Kali

Nmap, Metasploit, Burp Suite, Wireshark — что для чего и как начать.

Обзор С чего начать Инструменты Практика Защита Linux

Nmap — сканер сети

Первый инструмент, который надо освоить. Показывает открытые порты, сервисы, версии.

Основные команды

# Быстрый скан
nmap 192.168.1.1

# Скан портов + сервисы + версии
nmap -sV -sC 192.168.1.1

# Скан всех портов
nmap -p- 192.168.1.1

# Определить ОС
nmap -O 192.168.1.1

# Скан подсети
nmap -sn 192.168.1.0/24

# Сохранить результат
nmap -sV -oN scan.txt 192.168.1.1

Полезные флаги

  • -sS — SYN-скан (быстрый, «полуоткрытый»)
  • -sT — TCP connect (работает без root)
  • -sU — UDP-скан
  • -A — агрессивный (всё сразу)
  • -T4 — быстрее (T0–T5, где T5 самый быстрый)
Я начинал с `nmap -sV 192.168.1.1` на свой роутер. Понял, что вижу все порты, все сервисы. Это был «вау-момент» — как будто подсмотрел за кулисы.

Metasploit — фреймворк эксплуатации

Огромная база эксплойтов, payload'ов и модулей. Не «взлом в один клик», а платформа для работы.

Запуск

sudo msfconsole

Базовый воркфлоу

# Поиск модуля
search eternalblue

# Использовать модуль
use exploit/windows/smb/ms17_010_eternalblue

# Посмотреть опции
show options

# Настроить
set RHOSTS 192.168.1.10
set LHOST 192.168.1.5

# Проверить, уязвима ли цель
check

# Запустить
run

Полезные команды

help                    # справка
search тип:exploit имя  # поиск по типу
info                    # инфо о модуле
sessions -l             # список сессий
sessions -i 1           # войти в сессию
background              # свернуть сессию
Metasploit — мощный инструмент. Использовать только на своих системах или на легальных площадках (HTB, TryHackMe). Запуск эксплойта против чужой системы — уголовная ответственность.

Burp Suite — для веб-атак

Главный инструмент веб-пентестера. Перехватывает трафик между браузером и сервером, позволяет менять запросы, искать уязвимости.

Что умеет

  • Proxy — перехват и изменение HTTP-запросов
  • Repeater — повторная отправка запросов с изменениями
  • Intruder — автоматический перебор (пароли, ID, параметры)
  • Scanner — автоматический поиск уязвимостей (только в Pro)
  • Decoder — работа с Base64, URL, hex

Настройка

  1. Запусти Burp
  2. В браузере поставь прокси: 127.0.0.1:8080
  3. Установи сертификат Burp в браузер (для HTTPS)
  4. Включи перехват в Proxy → Intercept → On

Типичный сценарий

  1. Логинишься в тестовое приложение
  2. Перехватываешь запрос в Proxy
  3. Отправляешь в Repeater (Ctrl+R)
  4. Меняешь параметры, смотришь ответы
  5. Ищешь SQL-инъекции, XSS, IDOR
Burp — то, что отличает «я посмотрел курс» от «я умею». Именно в Repeater'е приходит понимание, как работают веб-приложения.

Wireshark — анализ трафика

Показывает все пакеты, которые идут через интерфейс. Незаменим для анализа сети, отладки и поиска утечек.

Запуск

sudo wireshark

Фильтры

ip.addr == 192.168.1.1          # по IP
tcp.port == 80                   # по порту
http                             # только HTTP
dns                              # только DNS
tcp.flags.syn == 1               # SYN-пакеты
http.request.method == "POST"    # POST-запросы

Что искать

  • Логины и пароли в открытом виде — HTTP, FTP, Telnet
  • Незашифрованные сессии — cookies без Secure-флага
  • Аномалии в трафике — странные запросы, необычные порты
  • Утечки данных — что уходит наружу

Follow TCP Stream

Правый клик на пакете → Follow → TCP Stream. Показывает всю переписку целиком, как читаемый текст.

Я нашёл дома «умную лампочку», которая каждые 30 секунд слала данные на китайский сервер. Wireshark показал это за 5 минут. С тех пор — все IoT-устройства у меня в отдельной сети.

Что ещё стоит знать

Для веб-пентеста

  • ffuf / gobuster — перебор директорий и параметров
  • sqlmap — автоматический поиск SQL-инъекций
  • nikto — быстрый скан веб-сервера на известные уязвимости
  • wfuzz — фаззинг параметров

Для сетевого пентеста

  • Responder — перехват NTLM-хешей в локальной сети
  • CrackMapExec / NetExec — работа с Active Directory
  • Impacket — набор Python-скриптов для SMB, Kerberos и т.д.

Для пассивной разведки

  • theHarvester — сбор email, доменов, имён
  • Amass — карта поддоменов организации
  • Shodan (shodan.io) — поисковик по открытым устройствам

Для паролей

  • John the Ripper — взлом хешей
  • Hashcat — быстрый взлом через GPU
  • Hydra — брутфорс логинов (SSH, FTP, HTTP)
Не пытайся выучить всё сразу. Я знаю 5 инструментов хорошо и 20 — поверхностно. Лучше глубина, чем ширина.
