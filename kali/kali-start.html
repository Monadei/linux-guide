С чего начать в ИБ

Мой путь от нуля: что учить, в каком порядке, что не работает.

Обзор С чего начать Инструменты Практика Защита Linux

Что нужно понять в начале

Пентест — это не «взломать за 5 минут». Это методичная работа: разведка, анализ, поиск уязвимостей, эксплуатация, отчёт. Инструменты — только 20% успеха. Остальное — понимание, как всё работает.

Я потратил первые 3 месяца на «смотрю видео и повторяю команды». Это была трата времени. Работает только когда понимаешь, что происходит под капотом. Начни с теории.

База, без которой некуда

1. Linux

Kali — это Linux. Без базы ты просто копируешь команды. Нужно понимать: файловую систему, права, процессы, сеть, bash-скрипты.

  • Шпаргалка по терминалу
  • Основы Bash
  • Файловая система
  • Сетевые команды

2. Сети

OSI-модель, TCP/IP, DNS, HTTP, порты. Что такое пакет, как он идёт, как читать Wireshark.

  • Как работает TCP handshake (SYN, SYN-ACK, ACK)
  • Что такое DNS и как работают запросы
  • Разница между HTTP и HTTPS
  • Что такое CIDR и как считать подсети

3. Веб

Большинство атак — на веб. Нужно понимать: HTML, HTTP-заголовки, cookies, сессии, SQL.

  • Как работает форма логина
  • Что такое SQL и как устроены базы
  • Разница между GET и POST
  • Как работают cookies и сессии

Установка Kali

Вариант 1: Виртуалка (рекомендую)

Так ты не сломаешь основную систему. VirtualBox или VMware, 4 ГБ RAM, 40 ГБ диск. Скачиваешь ISO с kali.org, ставишь как обычную систему.

sudo apt install virtualbox
# Скачай kali-linux-2024.x-installer-amd64.iso с kali.org
# Создай VM: 4 ГБ RAM, 40 ГБ диск, 2 ядра CPU
# Установи как обычный Linux

Вариант 2: Live USB

Для быстрых задач. Загружаешься с флешки, ничего не устанавливаешь. Минус — изменения не сохраняются (если не настроить persistence).

Вариант 3: WSL2 (Windows)

Если ты на Windows. Не всё работает, но база — да.

wsl --install -d kali-linux
У меня Kali стоит в VirtualBox на основном ПК и в отдельном разделе на MacBook. Виртуалка — идеально для экспериментов. Если сломаешь — снёс и создал заново.

Первые шаги в Kali

Обнови систему

sudo apt update && sudo apt full-upgrade -y

Посмотри, что установлено

# Список всех инструментов
ls /usr/share/kali-menu/

# Метапакеты по категориям
apt list --installed | grep kali-linux

Базовые команды для ориентира

ip a                    # сетевые интерфейсы
ip r                    # таблица маршрутов
ss -tulpn               # открытые порты
whoami                  # кто я
id                      # UID, GID, группы
uname -a                # инфа о ядре

Первый инструмент — nmap

Простой скан своей локальной сети:

# Найди свой IP
ip a

# Сканируй подсеть
sudo nmap -sn 192.168.1.0/24

# Скан конкретного хоста
sudo nmap -sV -sC 192.168.1.1
Сканировать можно только свои устройства или те, на которые есть разрешение. Скан чужой сети без разрешения = преступление.

Что делать дальше

План на первые 3 месяца

  1. Месяц 1: Linux + сеть. Читать, практиковать команды. Установить Kali в виртуалке, разобраться с базой.
  2. Месяц 2: Начать TryHackMe. Пройти комнаты для новичков (Pre Security, Intro to Cyber Security).
  3. Месяц 3: Параллельно читать про веб-уязвимости (OWASP Top 10). Начать HTB — самые лёгкие машины (Starting Point).

Что читать

  • «Web Application Hacker's Handbook» — библия веб-безопасности
  • «The Hacker Playbook 3» — практика пентеста
  • OWASP Top 10 — список главных веб-уязвимостей
  • HackTricks (hacktricks.xyz) — справочник техник
  • PayloadsAllTheThings (GitHub) — шпаргалки по payload'ам

Что смотреть

  • IppSec (YouTube) — разборы HTB-машин
  • John Hammond (YouTube) — CTF и малварь
  • NetworkChuck — для новичков
Не гонись за «сертификатами за месяц». Я вначале завидовал тем, кто сдавал OSCP. Понял: торопиться некуда. Лучше медленно, но с пониманием.
