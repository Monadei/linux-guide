GRUB — загрузчик Linux

Что это, где живёт, как настроить и восстановить.

Что такое GRUB

GRUB (GRand Unified Bootloader) — программа, которая запускается после UEFI/BIOS и загружает ядро. Показывает меню выбора ОС, если их несколько.

Где лежит

  • UEFI: /boot/efi/EFI/ubuntu/grubx64.efi
  • BIOS: в MBR диска
  • Конфиг: /boot/grub/grub.cfg — генерируется автоматически, вручную править нельзя
  • Настройки: /etc/default/grub и /etc/grub.d/

Основные настройки

sudo nano /etc/default/grub
GRUB_DEFAULT=0
GRUB_TIMEOUT=5
GRUB_TIMEOUT_STYLE=menu
GRUB_DISTRIBUTOR=`lsb_release -i -s 2> /dev/null || echo Debian`
GRUB_CMDLINE_LINUX_DEFAULT="quiet splash"
GRUB_CMDLINE_LINUX=""
  • GRUB_DEFAULT — пункт по умолчанию (0 = первый, "1>2" = подменю)
  • GRUB_TIMEOUT — сколько секунд показывать меню
  • GRUB_TIMEOUT_STYLE — menu, hidden, countdown
  • GRUB_CMDLINE_LINUX_DEFAULT — параметры ядра (nomodeset, quiet и т.д.)

После правок:

sudo update-grub

Параметры ядра

Полезные в GRUB_CMDLINE_LINUX_DEFAULT:

  • quiet — тихая загрузка
  • splash — графическая заставка
  • nomodeset — если чёрный экран с NVIDIA/AMD
  • nvidia-drm.modeset=1 — для Wayland с NVIDIA
  • acpi=off — если проблемы с питанием
  • noapic, nolapic — редко, для очень старого железа
  • mem_sleep_default=deep — фикс сна на некоторых ноутбуках

Темы GRUB

Скачай тему с gnome-look.org, распакуй в /boot/grub/themes/:

sudo mkdir -p /boot/grub/themes
sudo tar -xzf тема.tar.gz -C /boot/grub/themes/

В /etc/default/grub:

GRUB_THEME="/boot/grub/themes/имя/theme.txt"
sudo update-grub

Найти Windows

sudo os-prober
sudo update-grub

Если Windows не находится: убедись, что она выключена полностью (не гибернация), и что /boot/efi смонтирован.

Скрыть меню

GRUB_TIMEOUT=0
GRUB_TIMEOUT_STYLE=hidden

Меню можно вызвать, удерживая Shift при загрузке.

Восстановление GRUB

Если система не грузится — загрузись с Live USB, открой терминал:

# Найти корневой раздел
sudo fdisk -l

# Смонтировать (замени на свои)
sudo mount /dev/sda2 /mnt
sudo mount /dev/sda1 /mnt/boot/efi   # только для UEFI

# Смонтировать системные папки
for i in /dev /dev/pts /proc /sys /run; do sudo mount -B $i /mnt$i; done

# Chroot
sudo chroot /mnt

# Восстановить GRUB (для UEFI)
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=ubuntu
update-grub

# Для BIOS
grub-install /dev/sda
update-grub

# Выйти и перезагрузиться
exit
sudo umount -R /mnt
sudo reboot

Команды в меню GRUB

В меню нажми e — редактировать параметры выбранной загрузки. Полезно, чтобы добавить nomodeset на один раз. Изменения не сохраняются.

Нажми c — командная строка GRUB. Можно вручную загрузить систему:

ls
set root=(hd0,gpt2)
linux /boot/vmlinuz root=/dev/sda2
initrd /boot/initrd.img
boot

Скрыть recovery mode

В /etc/default/grub:

GRUB_DISABLE_RECOVERY=true
sudo update-grub
