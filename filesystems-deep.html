Файловые системы

ext4, Btrfs, XFS, ZFS, F2FS — что выбрать и почему.

ext4

Дефолт для большинства Linux-систем. Проверенная, стабильная, быстрая.

  • Плюсы: стабильность, простая, отлично документирована, проверена 15+ лет
  • Минусы: нет снапшотов, нет встроенного сжатия, нет контроля целостности
  • Когда: обычный десктоп, сервер, всё что требует надёжности без наворотов
  • Размер: до 1 ЭБ, файл до 16 ТБ

Btrfs

Современная ФС от Oracle. По умолчанию в Fedora, openSUSE. Активно используется в Synology NAS.

  • Плюсы: снапшоты, subvolumes, сжатие (zstd), контроль целостности, RAID на уровне ФС, можно менять размер онлайн
  • Минусы: исторически нестабильна (сейчас лучше), RAID 5/6 проблематичен, сложнее ext4
  • Когда: если нужны снапшоты и откаты (Timeshift на Btrfs — идеален)
  • Инструменты: btrfs subvolume list, btrfs filesystem usage

Пример: снапшот перед обновлением:

sudo btrfs subvolume snapshot / /.snapshots/$(date +%Y%m%d)

XFS

От SGI. Стандарт в RHEL. Отличная для больших файлов.

  • Плюсы: очень быстрая на больших файлах, надёжная, поддержка до 8 ЭБ, онлайн-дефрагментация
  • Минусы: нельзя уменьшить размер, нет снапшотов
  • Когда: серверы, базы данных, работа с большими файлами

ZFS

От Sun, теперь OpenZFS. Стандарт для NAS и серверов.

  • Плюсы: снапшоты, дедупликация, сжатие, RAIDZ, контроль целостности, шифрование
  • Минусы: требует много RAM (1 ГБ на 1 ТБ), лицензия CDDL (не в ядре Linux), сложная
  • Когда: NAS, серверы с большими объёмами, где важна сохранность данных
  • Установка: sudo apt install zfsutils-linux

F2FS

Flash-Friendly File System, от Samsung. Оптимизирована для флешек и SSD.

  • Плюсы: меньше износ SSD, лучше работает на SD-картах
  • Минусы: менее распространена, не так хорошо изучена
  • Когда: флешки, SD-карты, eMMC, Android-устройства

NTFS и exFAT

Для обмена с Windows.

  • NTFS — поддерживается через ntfs-3g или ядро (ntfs3)
  • exFAT — современный, поддержка в ядре, лучше для больших флешек
  • FAT32 — старый, ограничение 4 ГБ на файл
sudo apt install exfat-fuse exfatprogs
sudo apt install ntfs-3g

Создание файловой системы

sudo mkfs.ext4 /dev/sdb1
sudo mkfs.btrfs /dev/sdb1
sudo mkfs.xfs /dev/sdb1

Внимание: уничтожит все данные на разделе.

Проверка целостности

sudo fsck /dev/sdb1     # ext4
sudo btrfs check /dev/sdb1
sudo xfs_repair /dev/sdb1

Проверять только на размонтированном разделе. Или использовать sudo touch /forcefsck — при следующей загрузке.

Изменение размера

# ext4
sudo resize2fs /dev/sdb1

# Btrfs
sudo btrfs filesystem resize max /mount/point

# XFS — только увеличивать
sudo xfs_growfs /mount/point

Что выбрать для дома

  • Просто работает → ext4
  • Хочу снапшоты и откаты → Btrfs
  • NAS с бэкапами → ZFS
  • Флешка → exFAT или F2FS
  • Большие файлы на сервере → XFS
