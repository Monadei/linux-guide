Мои настройки

Что у меня стоит на Ubuntu 26.04. Полный список — чтобы было откуда начать.

Оформление

  • Тема: Aura-Glass (GTK2/3/4)
  • Иконки: Reversal-purple-dark
  • Курсор: aosp 20px
  • Шрифт: Ubuntu Sans 11pt
  • Окружение: GNOME 50.1
  • WM: Mutter (Wayland)

Железо

  • Процессор: Intel Core i5-12400F
  • Видеокарта: NVIDIA RTX 3050 8 GB
  • Память: 16 GB
  • Диск: SSD 456 GB (ext4) + 239 GB (NTFS)
  • Мониторы: 27" 240 Гц + 24" портрет 75 Гц

Что ставлю сразу после установки

flatpakУниверсальные приложения
timeshiftСнапшоты системы
gpartedРазделы диска
htopПроцессы в терминале
neofetch / fastfetchИнфо о системе
inxiЖелезо одним экраном
git curl wgetБазовые инструменты
gnome-tweaksТонкая настройка GNOME

Приложения

  • Браузер: Firefox (встроен) + Chrome
  • Терминал: GNOME Terminal + ZSH с Oh-My-Zsh
  • Редактор: VS Code + Neovim
  • Медиа: VLC, mpv
  • Графика: GIMP, Inkscape
  • Игры: Steam + Proton, Lutris, Heroic
  • Разработка: Docker, Python, Node.js

Полезные расширения GNOME

  • AppIndicator (иконки в трее)
  • Dash to Dock (док)
  • Blur My Shell (размытие)
  • Just Perfection (тонкая настройка)
  • Clipboard Indicator (история буфера)

Мой рабочий процесс

  1. Утром — sudo apt update && sudo apt upgrade
  2. Работа в VS Code + Firefox с кучей вкладок
  3. Сайт делаю в свободное время — правлю HTML/CSS/JS
  4. Игры — вечером, обычно Steam + Proton
  5. Раз в неделю — Timeshift-снапшот
  6. Раз в месяц — rsync важных данных на внешний диск
