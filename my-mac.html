MacBook Pro 2014

Все дистрибутивы, которые реально встают на MacBookPro11,x. С нюансами и гайдами.

МодельMacBook Pro (Retina, 13/15-inch, Mid 2014)
ИдентификаторMacBookPro11,1 / 11,2 / 11,3
ПроцессорIntel Core i5/i7 (Haswell)

Главная проблема: Wi-Fi Broadcom BCM4360 не работает из коробки. Драйвер broadcom-sta-dkms (Ubuntu/Mint/Debian) или akmod-wl (Fedora) или broadcom-wl-dkms (Arch). Исключение: Linux Mint 22 — драйвер уже в ISO.

Дистрибутивы, которые встают

Linux Mint 22 Проверено

Ubuntu-based, Cinnamon. Самый простой путь.

Пользователь из Японии поставил Mint 22 на точно такую же модель (Mid 2014, 13"). Wi-Fi драйвер был в ISO — не пришлось подключать кабель. Звук работал сразу, японская раскладка тоже. PyCharm и Sublime Text 4 работают. Есть специальный скрипт mintbook для автоматизации установки на MacBook Pro 2013–2015.
После обновления ядра до 7.0 может сломаться Wi-Fi. Решение: поставить broadcom-sta-dkms из noble-proposed или загрузиться со старого ядра 6.14, установить драйвер, потом обновиться. Canonical патчит wl для каждого ядра, но с задержкой.
  • Wi-Fi: в ISO для Mint 22 ✅
  • Камера: нужен facetimehd
  • Спящий режим: работает
  • HiDPI: настраивается
О Mint → Первые настройки → Скрипт mintbook →

Ubuntu 24.04 / 25.10 Проверено

Самый популярный Linux. GNOME, LTS, огромное сообщество.

Пользователь на Zenn поставил Ubuntu 25.10 на Intel MacBook Pro Mid 2014. Установка прошла без проблем, система работала «резво». Wi-Fi заработал после broadcom-sta-dkms. Японский ввод через fcitx5-mozc. Ubuntu Help содержит официальную страницу установки на MacBookPro11,1 с настройками efibootmgr и GRUB.
Wi-Fi не работает в Live-режиме. Нужен USB-Ethernet адаптер или tethering с телефона. После установки: sudo apt install broadcom-sta-dkms. Спящий режим может не работать — маскировка: sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target.
  • Wi-Fi: sudo apt install broadcom-sta-dkms
  • Камера: facetimehd-dkms (может быть не в репо)
  • Спящий режим: требует настройки
  • HiDPI: работает из коробки
Об Ubuntu → Первые настройки →

Fedora KDE Plasma Проверено

Свежие пакеты, современный интерфейс KDE.

Автор MacSales использовал Fedora KDE на точно таком же MacBook Pro mid-2014 (8 ГБ RAM) 30 дней. Установка прошла гладко. После установки драйвера Wi-Fi всё работало: клавиатура, тачпад, принтер, периферия. Другой пользователь на PC Weenies отметил, что система работает быстрее macOS.
Важно: начиная с Fedora 42 (2025), пакет akmod-wl больше не собирается для старых ядер Broadcom. Нужен USB Wi-Fi dongle или Thunderbolt-Ethernet. Либо использовать Fedora Silverblue (иммутабельная) — там драйвер можно поставить через rpm-ostree. Также slow wake from sleep — известная проблема.
  • Wi-Fi: akmod-wl (может не собраться)
  • Альтернатива: USB Wi-Fi dongle
  • Камера: facetimehd-kmod из COPR
  • Спящий режим: медленное пробуждение
О Fedora → Первые настройки →

Ultramarine Linux С нюансом

Fedora-based, дружелюбнее к железу.

Пользователь на Fosstodon использовал Ultramarine Linux (Fedora-based) на MacBook Air 2014 и Pro 2015. Единственная проблема — Wi-Fi (та же Broadcom). Всё остальное работало. Ultramarine включает дополнительные драйверы и кодеки из коробки.
Та же проблема с Broadcom, что и в Fedora. Нужен dongle или ручная установка akmod-wl.
  • Wi-Fi: та же проблема, что в Fedora
  • Плюс: больше драйверов из коробки

Pop!_OS С нюансом

Ubuntu-based от System76. Отдельные ISO для NVIDIA.

Pop!_OS — тот же Ubuntu под капотом, поэтому Wi-Fi Broadcom лечится так же: broadcom-sta-dkms. Плюс: если у тебя 15" MacBook Pro с NVIDIA GT 750M, у Pop!_OS есть отдельный ISO с драйверами NVIDIA — не придётся ставить вручную.
Для 13" модели (только Intel) бери generic ISO. Для 15" с NVIDIA — NVIDIA ISO. Secure Boot нужно отключить в Mac (Option → выбрать EFI Boot).
  • Wi-Fi: sudo apt install broadcom-sta-dkms
  • NVIDIA: отдельный ISO для 15"
  • Камера: facetimehd

Debian 13 Trixie Требует навыка

Стабильность, надёжность, долгая поддержка.

Пользователь на Codeberg установил Debian 13 Trixie на MacBookPro11,2 (15" Mid 2014). Использовал Thunderbolt-Ethernet адаптер для интернета. Wi-Fi работает, но драйвер не в установщике — нужно ставить офлайн. GNOME работает лучше, чем KDE (KDE плохо дружит со сном на этой модели).
Есть специальный offline-пакет: debian-intel-macbook-broadcom-offline на GitHub — 90+ .deb файлов с драйвером Broadcom. Скачиваешь на флешку, ставишь через dpkg -i *.deb потом dpkg --configure -a. Также нужен Thunderbolt-Ethernet для первой установки.
  • Wi-Fi: offline .deb пакет
  • Камера: facetimehd
  • Спящий режим: с GNOME работает
О Debian → Offline Broadcom пакет →

Arch Linux Для опытных

Rolling release, полный контроль, Arch Wiki.

Arch Wiki содержит отдельную страницу для MacBookPro11,x (включая твою модель). Там всё: Broadcom Wi-Fi, тачпад, HiDPI, звук, управление питанием, systemd-boot. Установка занимает время, но документация исчерпывающая.
Wi-Fi: для BCM4360 нужен broadcom-wl-dkms (проприетарный). b43 не поддерживает AC-версию чипа. Драйвер broadcom-wl есть в установщике Arch, но может потребоваться ручная загрузка. Тачпад: xf86-input-synaptics или mtrack. Камера: facetimehd-dkms из AUR. HiDPI: нужна ручная настройка.
  • Wi-Fi: broadcom-wl-dkms
  • Тачпад: xf86-input-synaptics / mtrack
  • Камера: facetimehd-dkms (AUR)
  • Загрузчик: systemd-boot или GRUB
Об Arch → Первые настройки → Arch Wiki для твоей модели →

LMDE 6 Стабильный вариант

Linux Mint на Debian, без Ubuntu.

Пользователь на Lemdro.id использовал LMDE на Mac Mini 2014 (то же железо, что в MacBook). Работает «очень хорошо». Плюс: rolling kernel updates не ломают Wi-Fi так часто, как в Ubuntu-based Mint. Рекомендуют для тех, кто устал от «Wi-Fi ломается после каждого обновления ядра».
LMDE использует Debian, а не Ubuntu. Wi-Fi драйвер нужно ставить через broadcom-sta-dkms после подключения по кабелю. Может потребоваться добавление non-free репозитория.
  • Wi-Fi: broadcom-sta-dkms
  • Стабильность: выше, чем Ubuntu-based
  • Камера: facetimehd

elementary OS Красивый вариант

Дизайнерский десктоп в стиле macOS.

Пользователь на Linux.org использовал elementary на точно такой же модели (Mid 2014). Работало. Wi-Fi Broadcom — та же проблема. Камера FaceTime не работала из коробки, нужно компилировать драйвер. NVIDIA на 15" — нужны драйверы.
Есть отдельный гайд elementary-on-a-mac на GitHub для dual-boot с macOS через rEFInd. Требует ubiquity -b (без установки GRUB). Если ставишь elementary, скорее всего понадобится ручная настройка загрузчика.
  • Wi-Fi: broadcom-sta-dkms
  • Камера: компиляция из исходников
  • NVIDIA: для 15"
О elementary → Гайд на GitHub →

NixOS Декларативный

Вся система в одном конфиге.

Пользователь на Lemdro.id поставил NixOS на MacBook Air 2014, скопировал конфиг со своего Framework ноутбука (поменял только hardware-config). «Просто работает». Все современные дистрибутивы должны работать.
Wi-Fi Broadcom настраивается через configuration.nix: boot.extraModulePackages = [ config.boot.kernelPackages.broadcom_sta ]; и boot.blacklistedKernelModules = [ "b43" "bcma" "ssb" ];. Кривая обучения крутая, но для MacBook работает.
  • Wi-Fi: через configuration.nix
  • Камера: facetimehd в nixpkgs
  • Спящий режим: настраивается

openSUSE Tumbleweed Rolling с нюансом

Rolling release от SUSE, YaST.

Пользователь на Lemdro.id рекомендовал openSUSE Tumbleweed для MacBook, если хочешь rolling release. SUSE хорошо поддерживает Broadcom через broadcom-wl. Но rolling release = kernel updates могут ломать Wi-Fi.
Wi-Fi драйвер broadcom-wl доступен в Packman репозитории. После каждого обновления ядра может потребоваться пересборка DKMS. Tumbleweed очень активно обновляется — следи за Wi-Fi.
  • Wi-Fi: broadcom-wl из Packman
  • Камера: facetimehd (проблематично)
  • Стабильность: ниже, чем LTS

Ключевые шаги для любого дистрибутива

  1. Скачай ISO нужного дистрибутива
  2. Запиши на флешку через balenaEtcher (на Mac или Ubuntu)
  3. Выключи Mac, вставь флешку, включи с зажатой Option (⌥)
  4. Выбери EFI Boot с флешки
  5. Загрузись в Live-режим — проверь Wi-Fi, звук, тачпад
  6. Подключи интернет через USB-Ethernet/телефон (Wi-Fi не работает до драйвера)
  7. Установи систему («Стереть диск» для Linux-only, или «Рядом с macOS»)
  8. После установки — поставь драйвер Wi-Fi
