Мой MacBook Pro 2014

Какой Linux поставить на старый Mac. Проверенные варианты с гайдами.

Что за машина

МодельMacBook Pro (Retina, 13-inch, Mid 2014)
ИдентификаторMacBookPro11,1
ПроцессорIntel Core i5 (Haswell), 2 ядра / 4 потока
Память8 ГБ (распаяна, не апгрейдится)
Диск128 ГБ SSD (Apple PCIe)
ГрафикаIntel Iris (встроенная)
Wi-FiBroadcom BCM4360 — требует драйвер
КамераFaceTime HD — требует facetimehd
Главная проблема: Wi-Fi Broadcom BCM4360 не работает из коробки ни в одном дистрибутиве. Драйвер проприетарный, его нельзя включить в ISO. Решение: подключись по кабелю через Thunderbolt-Ethernet адаптер, или через USB-модем с телефона, поставь драйвер, потом Wi-Fi заработает.

Три проверенных дистрибутива

Эти дистрибутивы реально ставили на MacBook Pro Mid 2014 разные люди. Не «должно работать», а «работало».

Fedora KDE Plasma Проверено

Что это: Fedora с рабочим столом KDE Plasma. Свежие пакеты, современный интерфейс.

Автор MacSales использовал Fedora KDE на точно таком же MacBook Pro mid-2014 (8 ГБ RAM) 30 дней. Установка прошла гладко, единственная проблема — Wi-Fi Broadcom. После установки драйвера всё работало: клавиатура, тачпад, принтер, периферия[citation:22]. Другой пользователь на PC Weenies тоже перешёл на Fedora KDE на этом же Mac и отметил, что система работает быстрее, чем macOS[citation:34].

Что работает

  • Wi-Fi (после установки akmod-wl)
  • Клавиатура, тачпад, подсветка
  • Звук, камера (после facetimehd)
  • Внешние мониторы через Thunderbolt
  • Принтеры

Что может не работать

  • FaceTime HD камера — нужен драйвер facetimehd-kmod из COPR[citation:28]
  • Спящий режим — иногда требует настройки
О Fedora → Первые настройки → Установка (похожая логика) →

Linux Mint 22 Проверено

Что это: Ubuntu-based дистрибутив с Cinnamon. Всё из коробки, дружелюбный.

Пользователь из Японии поставил Linux Mint 22 на MacBook Pro Retina 13" Mid 2014. Wi-Fi драйвер был в установщике Mint 22 — не пришлось подключать кабель. Звук работал без настройки, японская раскладка тоже. PyCharm и Sublime Text работают без проблем[citation:33]. Плюс есть специальный скрипт mintbook для MacBook Pro 2013–2015 — автоматизирует создание флешки и установку[citation:21].

Что работает

  • Wi-Fi (в Mint 22 драйвер уже в ISO!)
  • Звук, клавиатура, тачпад
  • Японская/русская раскладка
  • VNC, IDE, браузеры

Что может не работать

  • Камера — иногда требует настройки
  • Bluetooth — может отваливаться
О Mint → Первые настройки → Скрипт mintbook →

Ubuntu 24.04 / 25.10 Проверено

Что это: Самый популярный Linux. GNOME, LTS, огромное сообщество.

Пользователь на Zenn поставил Ubuntu 25.10 на Intel MacBook Pro Mid 2014. Установка прошла без проблем, система работала «резво». Wi-Fi заработал после broadcom-sta-dkms. Японский ввод через fcitx5-mozc[citation:36]. Ubuntu Help содержит официальную страницу установки на MacBookPro11,1 (2014) с настройками efibootmgr и GRUB[citation:30].

Что работает

  • Wi-Fi (после sudo apt install broadcom-sta-dkms)
  • Звук, клавиатура, тачпад
  • Русский/японский ввод
  • Спящий режим (с настройкой)

Что может не работать

  • Камера — нужен facetimehd
  • Автоматическая яркость клавиатуры
  • Спящий режим — иногда требует маскировки systemd targets
Об Ubuntu → Первые настройки → Официальный гайд →

Arch Linux Для опытных

Что это: Rolling release, полный контроль, легендарная вики.

Arch Wiki содержит отдельную страницу для MacBookPro11,x (включая твою модель). Там описаны все проблемы: Broadcom Wi-Fi, тачпад, HiDPI экран, звук, управление питанием[citation:29]. Xakep.ru публиковал гайд по установке Arch на MacBook Pro Retina 2014 с dual-boot, шифрованием LUKS и оптимизацией батареи[citation:35].

Что работает

  • Wi-Fi (через broadcom-wl или b43-firmware)
  • Тачпад (через xf86-input-synaptics или mtrack)
  • HiDPI (Retina) — настраивается
  • Звук, клавиатура

Что может не работать

  • Камера — facetimehd из AUR
  • Некоторые функции требуют ручной настройки
  • Установка занимает время
Об Arch → Первые настройки → Arch Wiki для твоей модели →

Что я рекомендую

Если хочешь просто чтобы работало — ставь Linux Mint 22. Драйвер Wi-Fi в ISO, всё из коробки, скрипт mintbook автоматизирует установку.

Если хочешь свежие пакеты и KDE — ставь Fedora KDE Plasma. Проверено на такой же машине, работает быстрее macOS.

Если хочешь хардкор и контроль — ставь Arch. Arch Wiki для твоей модели всё расскажет.

Перед установкой: сделай бэкап macOS через Time Machine. Установка Linux уничтожит всё на диске, если выберешь «Стереть диск». Для dual-boot нужно сначала сжать раздел macOS через diskutil.

Ключевые шаги для любого дистрибутива

  1. Скачай ISO нужного дистрибутива
  2. Запиши на флешку через balenaEtcher (на Mac или Ubuntu)
  3. Выключи Mac, вставь флешку, включи с зажатой клавишей Option (⌥)
  4. Выбери EFI Boot с флешки
  5. Загрузись в Live-режим (Try without installing) — проверь Wi-Fi, звук, тачпад
  6. Подключи интернет через кабель/телефон (Wi-Fi не работает до установки драйвера)
  7. Установи систему (выбери «Стереть диск» для Linux-only, или «Рядом с macOS»)
  8. После установки — поставь драйвер Wi-Fi

Драйвер Wi-Fi для каждой системы

ДистрибутивКоманда для Wi-Fi
Ubuntu / Mintsudo apt install broadcom-sta-dkms
Fedorasudo dnf install akmod-wl
Archsudo pacman -S broadcom-wl-dkms
Debiansudo apt install broadcom-sta-dkms (нужен offline-пакет)[citation:26]

Драйвер камеры (FaceTime HD)

ДистрибутивКоманда
Ubuntu / Mintsudo apt install facetimehd-dkms (может быть не в репо)
Fedorasudo dnf copr enable mulderje/facetimehd-kmod + sudo dnf install facetimehd-kmod[citation:28]
Archyay -S facetimehd-dkms
