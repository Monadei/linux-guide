Планировщик бэкапов

Что, куда, как часто. Собери свою стратегию бэкапов.

Принцип 3-2-1

Золотой стандарт бэкапов:

  • 3 копии данных (оригинал + 2 бэкапа)
  • 2 разных носителя (SSD + HDD, или диск + облако)
  • 1 копия вне дома (облако, у друга, в сейфе)

Правила бэкапов

  • Автоматически — если бэкап надо делать руками, ты его не будешь делать
  • Проверяй восстановление — бэкап, который не проверен, не бэкап
  • Не в той же комнате — пожар уничтожит и оригинал, и бэкап
  • Шифруй — если данные уехали в облако, шифруй перед отправкой
  • 3-2-1 — три копии, два носителя, одна вне дома

Timeshift — основа для системы

sudo apt install timeshift

# Настройка через GUI
sudo timeshift-launcher

# Создать снапшот вручную
sudo timeshift --create --comments "перед обновлением"

# Список снапшотов
sudo timeshift --list

# Восстановить
sudo timeshift --restore

Что не нужно бэкапить

  • ~/.cache — кеш, восстанавливается сам
  • /tmp — временные файлы
  • ~/.local/share/Trash — корзина
  • node_modules, venv, __pycache__ — восстанавливаются из манифестов
