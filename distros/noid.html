Noid Linux

Минималистичный дистрибутив на базе Void Linux с Xfce.

История

Noid Linux (Naz's Void Linux-based iso) — это персонализированная сборка Void Linux. Он предоставляет отполированный, готовый к использованию опыт, оставаясь верным минималистичной философии Void.

Особенности

    Основан на Void Linux с использованием runit.,Пакетный менеджер XBPS с собственным репозиторием.,Графический установщик Calamares.,Минимальный набор предустановленного ПО.

Кому подходит

Пользователям, которые хотят познакомиться с Void Linux в более дружелюбной форме.

Как скачать

Официальный сайт: https://noid.linux.org.
