Security Onion

Специализированная ОС для мониторинга безопасности и обнаружения вторжений.

История

Security Onion — дистрибутив для сетевой безопасности. Включает IDS/IPS, мониторинг трафика, анализ логов. Используется в корпоративной безопасности. Версия 3.3.0 вышла в сентябре 2026[citation:2].

Особенности

  • IDS/IPS для сетевой безопасности.
  • Мониторинг трафика и логов.
  • Инструменты для анализа инцидентов.
  • Версия 3.3.0 (сентябрь 2026).

Кому подходит

Специалистам по информационной безопасности и SOC-командам.
