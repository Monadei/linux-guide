PikaOS

Игровой дистрибутив на базе Debian с оптимизацией под Proton.

История

PikaOS — Debian-based дистрибутив, созданный специально для геймеров. Включает ядро с патчами для игр, свежие драйверы Mesa, Proton, WINE и GameMode из коробки.

Особенности

  • Основа — Debian.
  • Ядро с патчами для игр.
  • Proton, WINE, GameMode из коробки.
  • Свежие драйверы Mesa.
  • GNOME по умолчанию.

Кому подходит

Геймерам, которые хотят стабильный Debian с готовой игровой средой.
