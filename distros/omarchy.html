Omarchy

Набор конфигураций для Arch Linux от DHH. Превращает чистый Arch в готовую систему для веб-разработки.

История

Создан Дэвидом Хайнемайером Ханссоном (DHH), создателем Ruby on Rails. Omarchy — это не дистрибутив, а скрипт установки и набор конфигов поверх Arch Linux. Устанавливается одной командой: wget -qO- https://omarchy.org/install | bash[citation:4][citation:10].

Особенности

  • Основа — Arch Linux + Hyprland (тайловый композитор Wayland).
  • Предустановленные инструменты: Neovim, LazyGit, Docker, Alacritty, ZSH.
  • Полностью управляется с клавиатуры.
  • Одна команда установки — и получаешь готовую систему для разработки.
  • Автор — DHH, создатель Ruby on Rails.
  • Есть «bare mode» — без лишних приложений (Spotify, OBS и т.п.).
  • Full disk encryption через LUKS по умолчанию.

Кому подходит

Веб-разработчикам, которые хотят Arch + Hyprland без ручной настройки каждого конфига. Если ты уже знаком с Arch и хочешь готовую среду — это твой выбор.
