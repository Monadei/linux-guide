openSUSE Aeon

Иммутабельный десктопный дистрибутив openSUSE с автоматическими обновлениями.

История

Aeon (ранее openSUSE MicroOS Desktop) — версия openSUSE MicroOS для десктопа. Вся система иммутабельна, обновления приходят автоматически и атомарно, а приложения ставятся через Flatpak.

Особенности

  • Иммутабельный корень.
  • Автоматические атомарные обновления.
  • GNOME по умолчанию.
  • Flatpak для приложений.
  • Никакого управления пакетами вручную.
  • Идеален для тех, кто не хочет думать о системе.

Кому подходит

Пользователям, которые хотят «поставил и забыл» — система сама обновляется, сама чинится.
