Talos Linux

Специализированная ОС для запуска Kubernetes. Иммутабельная, минимальная, безопасная.

История

Talos Linux — независимый проект, созданный специально для Kubernetes. Не имеет SSH, shell, или традиционного пакетного менеджера. Всё управление через API. Версия 1.14.0 вышла в 2026 году[citation:16].

Особенности

  • Создана исключительно для Kubernetes.
  • Нет SSH, shell, пакетного менеджера.
  • Управление только через API.
  • Иммутабельная система.
  • DNS over TLS/HTTPS.
  • Btrfs как опция файловой системы.

Кому подходит

DevOps-инженерам и администраторам Kubernetes-кластеров. Не для десктопа.
