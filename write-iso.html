Как записать ISO на флешку

Три способа: GUI, терминал, Ventoy. Каждый в своей ситуации.

Windows — Rufus

  1. Скачай Rufus с официального сайта
  2. Вставь флешку (8+ ГБ)
  3. Выбери ISO, схема раздела — GPT, файловая система — FAT32
  4. Нажми «Старт». Все данные на флешке будут уничтожены

Linux / macOS — balenaEtcher

  1. Скачай balenaEtcher с balena.io
  2. Выбери ISO, выбери флешку, нажми Flash
  3. Готово. Простой интерфейс, ничего лишнего

Linux — терминал, dd

Сначала найди свою флешку:

lsblk

Обычно это /dev/sdb или /dev/sdc. Не перепутай с системным диском!

sudo dd if=~/Downloads/ubuntu.iso of=/dev/sdX bs=4M status=progress oflag=sync

Где /dev/sdX — твоя флешка (без цифры!). Ошибка здесь = потеря данных на диске.

Ventoy — мультизагрузочная флешка

Позволяет хранить несколько ISO на одной флешке. Ставится один раз, дальше просто копируешь файлы.

  1. Скачай Ventoy, установи на флешку
  2. Копируй любые ISO файлы на раздел Ventoy
  3. При загрузке выбираешь, что запускать

Идеально, если ты тестируешь много дистрибутивов.

Проверка ISO

Перед записью сравни SHA256 с сайтом дистрибутива:

sha256sum ~/Downloads/ubuntu.iso

Сравни результат с тем, что указан на сайте. Не сходится — перекачай.

Что выбрать

  • Windows — Rufus
  • Ubuntu / Mint / macOS — balenaEtcher
  • Любишь терминал — dd
  • Часто тестируешь дистрибутивы — Ventoy
