Драйверы NVIDIA в Linux

RTX 3050, 3060, 4060 — у всех одна история. Ставим правильно.

Ubuntu / Mint / Pop!_OS

Самый простой путь:

ubuntu-drivers devices

Покажет доступные драйверы. Потом:

sudo ubuntu-drivers autoinstall

Перезагрузка:

sudo reboot

Проверка:

nvidia-smi

Если видишь таблицу с GPU — всё работает.

Fedora

sudo dnf install https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm
sudo dnf install https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm
sudo dnf install akmod-nvidia
sudo dnf install xorg-x11-drv-nvidia-cuda

В Fedora 41+ с Secure Boot: потребуется подписать модуль через mokutil или отключить Secure Boot.

Arch / Manjaro / EndeavourOS

sudo pacman -S nvidia nvidia-utils nvidia-settings

Для старых карт (до GTX 900) — nvidia-470xx-dkms из AUR.

Для Wayland с Hyprland / Sway:

sudo pacman -S nvidia-dkms egl-wayland

NVIDIA + Wayland

С драйвером 495+ NVIDIA работает на Wayland. Нужны параметры ядра:

sudo nano /etc/default/grub

Добавь в строку GRUB_CMDLINE_LINUX_DEFAULT:

nvidia-drm.modeset=1

Обнови GRUB:

sudo update-grub

Если что-то сломалось

  • Чёрный экран — загрузись с параметром nomodeset, удали драйвер, поставь заново
  • Не грузится Wayland — переключись на X11 в меню входа
  • Низкий FPS в играх — проверь, что используешь nvidia-smi, а не встроенную графику
  • Пропало разрешение экрана — переустанови драйвер или пересобери initramfs

Моя конфигурация

У меня RTX 3050 8 GB. На Ubuntu 26.04 с GNOME на Wayland драйвер встал без проблем через ubuntu-drivers autoinstall. Для игр — Steam + Proton, всё работает.
