Шрифты для Linux

Что ставить, откуда брать, как настраивать.

Моноширинные (для кода и терминала)

  • JetBrains Mono — лигатуры, отличная читаемость. sudo apt install fonts-jetbrains-mono
  • Fira Code — классика с лигатурами. sudo apt install fonts-firacode
  • Cascadia Code — от Microsoft, лигатуры. sudo apt install fonts-cascadia-code
  • Hack — минимализм без лигатур. sudo apt install fonts-hack
  • IBM Plex Mono — строгий корпоративный. sudo apt install fonts-ibm-plex
  • Iosevka — узкий, экономит место. Установка вручную
  • Ubuntu Mono — встроенный, нейтральный
  • Source Code Pro — от Adobe, открытый

Системные (для интерфейса)

  • Inter — современный, читаемый. sudo apt install fonts-inter
  • Roboto — от Google. sudo apt install fonts-roboto
  • Noto Sans — поддержка всех языков. sudo apt install fonts-noto
  • Cantarell — для GNOME
  • Ubuntu — для Ubuntu. sudo apt install fonts-ubuntu
  • San Francisco — копия Apple SF. Нет в репозиториях
  • Open Sans — универсальный. sudo apt install fonts-open-sans

Установка вручную

Скачал .ttf или .otf — положи в ~/.local/share/fonts/:

mkdir -p ~/.local/share/fonts
cp ~/Downloads/шрифт.ttf ~/.local/share/fonts/
fc-cache -fv

Системно (для всех пользователей):

sudo cp шрифт.ttf /usr/share/fonts/truetype/
sudo fc-cache -fv

Настройка в системе

GNOME: gnome-tweaks → Fonts.

Вручную через ~/.config/fontconfig/fonts.conf:

<?xml version="1.0"?>
<!DOCTYPE fontconfig SYSTEM "fonts.dtd">
<fontconfig>
  <match target="pattern">
    <test qual="any" name="family"><string>sans-serif</string></test>
    <edit name="family" mode="assign" binding="strong">
      <string>Inter</string>
    </edit>
  </match>
</fontconfig>

Перезагрузить кеш:

fc-cache -fv

Проверка

fc-list | grep -i jetbrains
fc-match sans-serif
fc-match monospace

Настройка сглаживания

GNOME Tweaks → Fonts → Antialiasing. Обычно:

  • Antialiasing: Standard (grayscale)
  • Hinting: Slight
  • Subpixel: для LCD-мониторов включить RGBA

Emoji

sudo apt install fonts-noto-color-emoji

Проверка: fc-list | grep -i emoji
