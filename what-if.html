Что делать, если...

Типичные проблемы и как их решить.

Не грузится система

Загрузись с Live USB, открой терминал и восстанови GRUB:

sudo mount /dev/sdaX /mnt
sudo mount /dev/sdaY /mnt/boot/efi
for i in /dev /dev/pts /proc /sys /run; do sudo mount -B $i /mnt$i; done
sudo chroot /mnt
grub-install /dev/sda
update-grub
exit

Чёрный экран после установки

В меню GRUB нажми e, найди строку с linux, добавь nomodeset в конце. Загрузишься в базовом режиме. Дальше — установи драйвер NVIDIA.

Нет звука

sudo apt install pulseaudio pavucontrol
pavucontrol

Проверь, что нужное устройство выбрано в Output Devices.

Не работает Wi-Fi

lspci | grep -i network
sudo apt install linux-firmware
sudo apt install bcmwl-kernel-source

Не монтируется диск Windows (NTFS)

sudo apt install ntfs-3g

Если Windows не выключена полностью — загрузись в Windows и выключи Fast Startup.

Клавиатура или мышь не работают

Перезагрузись с i8042.nomux=1 в параметрах ядра. Или проверь USB-порты.

Не хватает места на /

sudo apt autoremove
sudo apt clean
sudo journalctl --vacuum-size=100M

Забыл пароль root

В меню GRUB нажми e, в конце строки linux добавь init=/bin/bash, загрузись. Потом:

mount -o remount,rw /
passwd ваш_логин
reboot -f

Система тормозит

htop
systemd-analyze blame
sudo systemctl disable ненужный_сервис

Не открывается сайт

ping ya.ru
nslookup ya.ru
cat /etc/resolv.conf

Проверь DNS: nameserver 8.8.8.8 в /etc/resolv.conf.
