Игры в Linux

Steam, Proton, Lutris, Heroic. Как запускать Windows-игры и не страдать.

Steam + Proton

90% игр работают из коробки:

  1. Установи Steam: sudo apt install steam
  2. Настройки → Совместимость → включи «Steam Play для всех игр»
  3. Выбери Proton Experimental или Proton 9
  4. Играй

Проверить, работает ли твоя игра: protondb.com.

Heroic Games Launcher

Для игр из Epic Games Store и GOG:

flatpak install flathub com.heroicgameslauncher.hgl

Работает на Proton и Wine. Установка в один клик из Flatpak.

Lutris

Для не-Steam игр, эмуляторов, старых игр:

sudo apt install lutris

Lutris сам настраивает Wine под каждую игру. Есть готовые скрипты для тысяч игр.

Bottles

Для Windows-приложений через Wine:

flatpak install flathub com.usebottles.bottles

Проще, чем ручной Wine. Создаёт «бутылки» под каждое приложение.

MangoHud — FPS-оверлей

sudo apt install mangohud

Запуск: mangohud %command% в параметрах запуска игры в Steam. Покажет FPS, температуру, загрузку GPU.

GameMode

sudo apt install gamemode

Автоматически повышает приоритет игры. В Steam: gamemoderun %command%.

Что НЕ работает

  • Игры с античитом на уровне ядра (Valorant, Fortnite, PUBG, GTA Online)
  • Некоторые MMO с агрессивным античитом
  • Свежие AAA в день релиза (иногда нужно пару недель на патчи Proton)

BattlEye и Easy Anti-Cheat работают, если разработчик включил Linux-поддержку. Многие включили (Apex, Rust, Elden Ring).

Мой опыт с RTX 3050

На Ubuntu 26.04 с драйвером NVIDIA и Proton 9 большинство игр идут без проблем. Для тяжёлых случаев — PROTON_USE_WINED3D=0 и DXVK. Мой топ работает: Cyberpunk 2077, Elden Ring, Hollow Knight, Hades.
