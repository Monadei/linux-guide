Arch — что после установки

Что делать сразу после установки.

1. Обновление

sudo pacman -Syu

2. Пользователь и sudo

sudo pacman -S sudo
EDITOR=vim visudo
# Раскомментируй %wheel ALL=(ALL:ALL) ALL
sudo usermod -aG wheel $USER

3. GNOME

sudo pacman -S xorg gnome gnome-tweaks gdm
sudo systemctl enable gdm
sudo reboot

4. Звук

sudo pacman -S pipewire pipewire-pulse pipewire-alsa wireplumber
systemctl --user enable --now pipewire pipewire-pulse wireplumber

5. AUR — yay

sudo pacman -S git base-devel
git clone https://aur.archlinux.org/yay.git
cd yay && makepkg -si

6. Базовый софт

sudo pacman -S firefox vlc htop neofetch curl wget
yay -S google-chrome visual-studio-code-bin

7. NVIDIA

sudo pacman -S nvidia nvidia-utils nvidia-settings
sudo reboot
nvidia-smi
