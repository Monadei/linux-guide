Hyprland — конфиг

Тайловый Wayland-композитор с анимациями.

Что это

Hyprland — современный тайловый композитор для Wayland. Анимации, гибкость, красота. Используется в Omarchy.

Установка (Arch)

sudo pacman -S hyprland kitty waybar wofi
yay -S hyprpaper swww

Базовый конфиг

# ~/.config/hypr/hyprland.conf

monitor=,preferred,auto,1

exec-once = waybar &
exec-once = hyprpaper &
exec-once = mako

$mod = SUPER

bind = $mod, Return, exec, kitty
bind = $mod, Q, killactive
bind = $mod, E, exec, dolphin
bind = $mod, R, exec, wofi --show drun
bind = $mod, 1, workspace, 1
bind = $mod, 2, workspace, 2

animations {
    enabled = yes
    bezier = myBezier, 0.05, 0.9, 0.1, 1.05
    animation = windows, 1, 7, myBezier
    animation = fade, 1, 7, default
}

Компоненты

  • waybar — статусбар
  • wofi / rofi — лаунчер
  • hyprpaper — обои
  • swww — анимированные обои
  • mako / dunst — уведомления
