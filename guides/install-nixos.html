Установка NixOS

Декларативная система — вся конфигурация в одном файле.

Что это

NixOS — не обычный дистрибутив. Вся система описывается в файле /etc/nixos/configuration.nix. Обновления атомарные, откат в одну команду.

Установка

  1. Скачай ISO с nixos.org
  2. Загрузись с флешки
  3. Разметь диск
  4. Примонтируй в /mnt
  5. Запусти nixos-generate-config --root /mnt
  6. Отредактируй /mnt/etc/nixos/configuration.nix
  7. nixos-install

Минимальный configuration.nix

{ config, pkgs, ... }:

{
  imports = [ ./hardware-configuration.nix ];

  boot.loader.systemd-boot.enable = true;
  boot.loader.efi.canTouchEfiVariables = true;

  networking.hostName = "nixos-pc";
  networking.networkmanager.enable = true;

  time.timeZone = "Europe/Moscow";
  i18n.defaultLocale = "ru_RU.UTF-8";

  users.users.monadei = {
    isNormalUser = true;
    extraGroups = [ "wheel" "networkmanager" ];
  };

  environment.systemPackages = with pkgs; [
    firefox vim git htop
  ];

  services.xserver.enable = true;
  services.xserver.displayManager.gdm.enable = true;
  services.xserver.desktopManager.gnome.enable = true;

  system.stateVersion = "24.05";
}

Обновление системы

sudo nixos-rebuild switch
sudo nixos-rebuild switch --rollback
sudo nix-env --list-generations --profile /nix/var/nix/profiles/system
