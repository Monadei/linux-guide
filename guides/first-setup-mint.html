Mint — что после установки

Что делать сразу после установки.

1. Обновление

sudo apt update && sudo apt upgrade -y

2. Драйверы

Открой меню → Драйверы. Или:

sudo apt install mintdrivers

3. Timeshift

Уже установлен. Открой Timeshift → настрой снапшоты (ежедневно, 5 хранить).

4. Базовый софт

sudo apt install htop neofetch inxi gnome-disk-utility
sudo apt install vlc gimp kdenlive

5. Что уже есть

  • Кодеки, драйверы, шрифты
  • Timeshift, Update Manager
  • Firefox, LibreOffice, VLC, GIMP
  • Warpinator, Hypnotix
