AppArmor

Мандатный доступ в Ubuntu/SUSE.

Что это

AppArmor — альтернатива SELinux. Проще, привязан к путям файлов.

Статус

sudo aa-status
sudo apparmor_status

Профили

ls /etc/apparmor.d/
sudo apparmor_parser -r /etc/apparmor.d/usr.bin.firefox
sudo ln -s /etc/apparmor.d/usr.bin.firefox /etc/apparmor.d/disable/

Режимы

sudo aa-complain /usr/bin/firefox   # только логирует
sudo aa-enforce /usr/bin/firefox    # блокирует

Логи

sudo journalctl -k | grep apparmor
sudo dmesg | grep apparmor
