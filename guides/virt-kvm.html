KVM + QEMU

Нативная виртуализация Linux.

Что это

KVM — модуль ядра для виртуализации. QEMU — эмулятор. Вместе дают быстрые виртуалки.

Проверка поддержки

egrep -c "(vmx|svm)" /proc/cpuinfo

Установка

sudo apt install qemu-kvm libvirt-daemon-system virt-manager
sudo usermod -aG libvirt,kvm $USER
# Перелогинься

GUI

virt-manager

CLI

sudo virt-install --name ubuntu-vm --ram 4096 --vcpus 2 --disk path=/var/lib/libvirt/images/ubuntu.qcow2,size=40 --cdrom ubuntu.iso

Управление

virsh list --all
virsh start ubuntu-vm
virsh shutdown ubuntu-vm
