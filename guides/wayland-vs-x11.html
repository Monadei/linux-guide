Wayland vs X11

Что такое Wayland и X11, в чём разница, что выбрать.

Коротко

  • X11 — старый протокол графики (1984). Работает, но устарел.
  • Wayland — современный протокол (2008). Заменяет X11.

Почему X11 устарел

  • Задержки при вводе (input lag) — из-за трёх процессов: сервер, композитор, приложение
  • Проблемы с HiDPI и разными мониторами
  • Нет нормальной изоляции приложений
  • Теряется плавность при 144+ Гц
  • Код огромный и запутанный

Что даёт Wayland

  • Плавнее, быстрее, меньше лагов
  • Отличная поддержка HiDPI и нескольких мониторов
  • Изоляция приложений (нет доступа к чужим окнам)
  • Нормальная работа 144+ Гц
  • Жесты тачпада

Минусы Wayland

  • NVIDIA — долго был плохо, сейчас лучше с драйвером 495+
  • Некоторые приложения не работают нативно (XWayland спасает)
  • Скриншотеры типа Flameshot могут глючить
  • Запись экрана через OBS — иногда нужно настраивать
  • Терминальные мультиплексоры типа tmux — ок, но есть нюансы

Как узнать, что у тебя

echo $XDG_SESSION_TYPE
# Выведет "wayland" или "x11"

loginctl show-session $(loginctl | grep $(whoami) | awk '{print $1}') -p Type

Как переключиться

Ubuntu / GNOME

На экране входа нажми на шестерёнку → выбери «GNOME on Xorg».

Fedora / KDE

На экране входа внизу справа выбери «Plasma (X11)».

Постоянно — через GDM

sudo nano /etc/gdm3/custom.conf
# Раскомментируй:
# WaylandEnable=false
sudo systemctl restart gdm3

NVIDIA + Wayland

С драйвером 495+ работает. Нужно включить:

sudo nano /etc/default/grub
# GRUB_CMDLINE_LINUX_DEFAULT="quiet splash nvidia-drm.modeset=1"
sudo update-grub
sudo reboot

Проверка:

nvidia-smi
echo $XDG_SESSION_TYPE

Итог

  • Intel / AMD GPU — смело на Wayland
  • NVIDIA 495+ — Wayland работает, но иногда с нюансами
  • Старые NVIDIA — сиди на X11
  • Xfce / MATE / Cinnamon — пока X11
  • Нужен Flameshot / старые приложения — X11
