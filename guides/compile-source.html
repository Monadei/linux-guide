Компиляция из исходников

./configure, make, make install — как собрать программу самому.

Когда это нужно

  • Пакета нет в репозитории
  • Нужна свежая версия
  • Нужны особые флаги компиляции
  • Хочешь понять, как устроена сборка

Что понадобится

# Debian/Ubuntu
sudo apt install build-essential

# Fedora
sudo dnf groupinstall "Development Tools"

# Arch
sudo pacman -S base-devel

Классические шаги

# 1. Скачать исходники
wget https://example.com/program-1.0.tar.gz
tar -xzf program-1.0.tar.gz
cd program-1.0

# 2. Прочитать README и INSTALL
cat README
cat INSTALL

# 3. Конфигурация
./configure --prefix=/usr/local
# Или с опциями:
./configure --prefix=/usr/local --enable-feature --disable-other

# 4. Сборка
make -j$(nproc)                   # использует все ядра

# 5. Установка
sudo make install

# 6. Проверка
which program
program --version

Если нет ./configure

Некоторые проекты используют другие системы сборки:

# CMake
mkdir build && cd build
cmake ..
make -j$(nproc)
sudo make install

# Meson
meson setup build
cd build
ninja
sudo ninja install

# Rust
cargo build --release
sudo cp target/release/program /usr/local/bin/

# Go
go build
sudo cp program /usr/local/bin/

Типичные проблемы

Нет зависимости

configure: error: library X not found
# Решение: установить dev-пакет
sudo apt install libX-dev
sudo dnf install X-devel
sudo pacman -S x

Нет компилятора

configure: error: C compiler not found
sudo apt install gcc g++

Ошибка make

Читай последние 10 строк — там обычно сказано, чего не хватает.

Хочешь удалить

# Если в исходниках осталось
sudo make uninstall

# Иначе вручную
sudo rm /usr/local/bin/program
sudo rm -rf /usr/local/share/program

Правило хорошего тона

  • Сначала ищи в репозитории — apt search программу
  • Потом Flatpak — flatpak search программу
  • Потом AppImage — скачай и запусти
  • И только потом — компиляция из исходников

Причина: пакеты из репозитория обновляются автоматически. Скомпилированные вручную — нет, придётся обновлять руками.

Установка в /usr/local

Если собираешь из исходников — ставь в /usr/local, не в /usr. Это не перезапишет системные пакеты.

./configure --prefix=/usr/local
make
sudo make install

# Программа будет в /usr/local/bin/
which program
# /usr/local/bin/program
