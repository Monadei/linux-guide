chmod — права доступа

rwx, 755, 644.

Что такое права

Каждый файл имеет три категории прав: владелец, группа, остальные. Каждая — rwx.

Просмотр

ls -la
-rwxr-xr-x 1 monadei monadei 4096 file.sh

Числовая запись

ЧислоБуквыПрава
7rwxполные
6rw-чтение+запись
5r-xчтение+выполнение
4r--чтение
0---нет прав

Популярные

chmod 755 file   # rwxr-xr-x
chmod 644 file   # rw-r--r--
chmod 600 file   # rw------- (SSH ключи)
chmod 700 dir    # rwx------
chmod 777 file   # ОПАСНО
chmod +x file
chmod -R 755 папка/

Специальные биты

  • 4xxx — SUID
  • 2xxx — SGID
  • 1xxx — sticky bit
chmod 1777 /tmp
chmod 4755 /usr/bin/passwd
