Ubuntu — что после установки

Что делать сразу после установки.

1. Обновление

sudo apt update && sudo apt upgrade -y
sudo apt autoremove -y

2. Драйверы NVIDIA

ubuntu-drivers devices
sudo ubuntu-drivers autoinstall
sudo reboot

3. Кодеки и шрифты

sudo apt install ubuntu-restricted-extras
sudo apt install fonts-jetbrains-mono fonts-firacode

4. Базовый софт

sudo apt install curl wget git htop neofetch inxi
sudo apt install gparted timeshift vlc gimp
sudo apt install gnome-tweaks gnome-shell-extensions

5. Flatpak

sudo apt install flatpak
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

6. Timeshift

sudo timeshift --create --comments "Первый снэпшот"

7. Firewall

sudo ufw enable
sudo ufw default deny incoming
sudo ufw default allow outgoing
