LXC / LXD

Системные контейнеры.

Что это

LXC — контейнеры на уровне системы. LXD — менеджер LXC. Похоже на виртуалки, но быстрее.

Установка

sudo apt install lxd
sudo lxd init

Основы

lxc list
lxc launch ubuntu:22.04 mycontainer
lxc exec mycontainer bash
lxc stop mycontainer
lxc delete mycontainer

Файлы и порты

lxc file push file.txt mycontainer/root/
lxc config device add mycontainer myport80 proxy listen=tcp:0.0.0.0:8080 connect=tcp:127.0.0.1:80
