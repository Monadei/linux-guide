ZFS

Для NAS и серверов. Максимальная надёжность.

Что это

ZFS — ФС от Sun (теперь OpenZFS). Стандарт для NAS. Снапшоты, дедупликация, RAIDZ, шифрование.

Плюсы и минусы

Плюсы: снапшоты, дедупликация, сжатие, RAIDZ, контроль целостности, шифрование.

Минусы: требует много RAM (1 ГБ на 1 ТБ), лицензия CDDL.

Установка

# Ubuntu
sudo apt install zfsutils-linux

# Fedora
sudo dnf install zfs

Создание пула

sudo zpool create tank /dev/sdb              # простой
sudo zpool create tank mirror /dev/sdb /dev/sdc  # зеркало
sudo zpool create tank raidz /dev/sdb /dev/sdc /dev/sdd  # RAIDZ1
sudo zpool create -O compression=lz4 tank /dev/sdb

Datasets

sudo zfs create tank/documents
zfs list
sudo zfs set compression=zstd tank/documents
sudo zfs set quota=100G tank/photos

Снапшоты

sudo zfs snapshot tank/documents@backup-$(date +%Y%m%d)
zfs list -t snapshot
sudo zfs rollback tank/documents@backup-20260101

Обслуживание

sudo zpool status
sudo zpool scrub tank
zpool history
