Курсоры

Установка курсоров.

Популярные

  • Bibata — современный, круглый
  • Phinger — минималистичный
  • WhiteSur — macOS-стиль

Установка

sudo apt install bibata-cursor-theme
mkdir -p ~/.icons
cp -r cursor-theme/ ~/.icons/

Настройка

gsettings set org.gnome.desktop.interface cursor-theme "Bibata-Modern-Ice"
