i3 — конфиг

Классический тайловый WM для X11.

Что это

i3 — самый популярный тайловый оконный менеджер. X11, стабильный, минималистичный.

Установка

sudo apt install i3 i3status dmenu i3blocks

Базовый конфиг

# ~/.config/i3/config

set $mod Mod4
font pango:JetBrains Mono 11

exec --no-startup-id picom -b
exec --no-startup-id feh --bg-fill ~/Pictures/wallpaper.jpg

bindsym $mod+Return exec alacritty
bindsym $mod+Shift+q kill
bindsym $mod+d exec rofi -show drun

bindsym $mod+1 workspace 1
bindsym $mod+2 workspace 2
bindsym $mod+h split h
bindsym $mod+v split v
bindsym $mod+space focus mode_toggle
bindsym $mod+f fullscreen toggle
bindsym $mod+Shift+c reload

Компоненты

  • i3status / i3blocks / polybar — статусбар
  • rofi / dmenu — лаунчер
  • picom — композитор
  • feh / nitrogen — обои
