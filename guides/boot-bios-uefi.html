Как узнать, что у тебя

[ -d /sys/firmware/efi ] && echo "UEFI" || echo "BIOS"
lsblk | grep efi

Secure Boot

Только Ubuntu, Fedora, RHEL, openSUSE поддерживают из коробки. Для других — отключить в BIOS.

EFI-раздел

Для UEFI нужен раздел EFI (FAT32, 512 МБ). Монтируется в /boot/efi.
