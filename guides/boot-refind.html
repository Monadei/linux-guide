rEFInd

Красивый графический загрузчик.

Что это

rEFInd — графический загрузчик для UEFI. Автоматически находит все ОС.

Установка (Ubuntu)

sudo apt-add-repository ppa:rodsmith/refind
sudo apt update
sudo apt install refind

Установка (Arch)

sudo pacman -S refind
sudo refind-install

Темы

Скачай с github.com/bobafetthotmail/refind-theme-regular

sudo cp -r theme /boot/efi/EFI/refind/themes/
# В refind.conf:
# include themes/refind-theme-regular/theme.conf
