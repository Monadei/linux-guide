Установка Gentoo

Сборка из исходников. Долго, но даёт полный контроль.

Подготовка

Gentoo — не для слабых. Установка займёт часы, иногда дни. Нужны:

  • Минимум 4 ГБ RAM (лучше 8+)
  • Много свободного времени
  • Терпение

Скачай minimal installation CD с gentoo.org.

Разметка и монтирование

fdisk /dev/sda
mkfs.ext4 /dev/sda2
mount /dev/sda2 /mnt

Скачивание stage3

cd /mnt
wget https://distfiles.gentoo.org/releases/amd64/autobuilds/...tar.xz
tar xpvf stage3-*.tar.xz --xattrs-include='*.*' --numeric-owner

Настройка make.conf

nano /mnt/etc/portage/make.conf

COMMON_FLAGS="-O2 -pipe -march=native"
MAKEOPTS="-j8"
USE="X wayland gnome -kde"

Chroot и сборка

mount --types proc /proc /mnt/proc
mount --rbind /sys /mnt/sys
mount --make-rslave /mnt/sys
mount --rbind /dev /mnt/dev
mount --make-rslave /mnt/dev

chroot /mnt /bin/bash
source /etc/profile

emerge-webrsync
emerge --sync

eselect profile list
eselect profile set 1

emerge --ask --verbose --update --deep --newuse @world

Ядро и загрузчик

emerge --ask sys-kernel/gentoo-sources
cd /usr/src/linux
make menuconfig
make -j8 && make modules_install && make install

emerge --ask sys-boot/grub
grub-install --target=x86_64-efi --efi-directory=/boot
grub-mkconfig -o /boot/grub/grub.cfg
