Установка Alpine

Крошечная система для контейнеров и встраиваемых устройств.

Загрузка и вход

Загрузись с ISO Alpine (standard или extended). Войди как root (без пароля).

Запуск установщика

setup-alpine

Отвечай на вопросы:

  • Раскладка: us ru
  • Имя хоста: alpine-pc
  • Интерфейс: eth0
  • IP: dhcp
  • Пароль root — задай
  • Часовой пояс: Europe/Moscow
  • Зеркало: выбери ближайшее
  • SSH: openssh
  • Диск: sda, схема sys

После установки

apk update
apk upgrade

apk add sudo vim bash bash-completion

adduser monadei
adduser monadei wheel
visudo  # раскомментировать %wheel

Особенности

  • Менеджер пакетов: apk
  • Init: OpenRC (не systemd)
  • Управление сервисами: rc-service nginx start
  • Автозапуск: rc-update add nginx default
