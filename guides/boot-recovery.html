Восстановление загрузки

Если GRUB или systemd-boot сломались.

Что делать

Загрузись с Live USB, открой терминал.

Восстановление GRUB (UEFI)

sudo fdisk -l
sudo mount /dev/sda2 /mnt
sudo mount /dev/sda1 /mnt/boot/efi
for i in /dev /dev/pts /proc /sys /run; do sudo mount -B $i /mnt$i; done
sudo chroot /mnt
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=ubuntu
update-grub
exit
sudo umount -R /mnt
sudo reboot

Восстановление GRUB (BIOS)

sudo mount /dev/sda1 /mnt
for i in /dev /dev/pts /proc /sys /run; do sudo mount -B $i /mnt$i; done
sudo chroot /mnt
grub-install /dev/sda
update-grub
exit
sudo umount -R /mnt
sudo reboot

Если не помогает

  • Super GRUB2 Disk
  • Переустановка загрузчика с нуля
  • Live USB с rEFInd
