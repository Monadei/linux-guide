ext4

Стандарт Linux. Проверена временем.

Что это

ext4 — расширенная версия ext3. Дефолт для большинства Linux.

Плюсы и минусы

Плюсы: стабильность, простота, документирована.

Минусы: нет снапшотов, нет сжатия, нет контроля целостности.

Создание и монтирование

sudo mkfs.ext4 /dev/sdb1
sudo mount /dev/sdb1 /mnt/data
sudo fsck /dev/sdb1
sudo dumpe2fs /dev/sdb1 | head -30

Изменение размера

# Увеличить
sudo umount /dev/sdb1
sudo resize2fs /dev/sdb1

# Уменьшить
sudo e2fsck -f /dev/sdb1
sudo resize2fs /dev/sdb1 100G
