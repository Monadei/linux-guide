Sway — конфиг

i3 для Wayland.

Что это

Sway — тайловый композитор Wayland, совместимый с конфигом i3. Полная замена i3 в мире Wayland.

Установка

sudo apt install sway swaybg swayidle swaylock waybar wofi

Конфиг

# ~/.config/sway/config

set $mod Mod4
set $term alacritty
set $menu wofi --show drun

output * bg ~/Pictures/wallpaper.jpg fill

bindsym $mod+Return exec $term
bindsym $mod+d exec $menu
bindsym $mod+Shift+q kill
bindsym $mod+1 workspace 1
bindsym $mod+2 workspace 2
bindsym $mod+h split h
bindsym $mod+v split v
bindsym $mod+space floating toggle
bindsym $mod+f fullscreen toggle

bar {
    swaybar_command waybar
}

Компоненты

  • waybar — статусбар
  • wofi — лаунчер
  • swaybg — обои
  • swaylock — блокировка
  • grimshot — скриншоты
