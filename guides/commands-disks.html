Диски и разделы

lsblk, df, mount, fdisk.

Информация

lsblk
lsblk -f
df -h
du -sh папка/
fdisk -l

Монтирование

sudo mkdir /mnt/disk
sudo mount /dev/sdb1 /mnt/disk
sudo umount /mnt/disk
# /etc/fstab: UUID=xxx /mnt/disk ext4 defaults 0 2

Разметка

sudo fdisk /dev/sdb
# n — новый, d — удалить, p — показать, w — записать, q — выйти

GParted

sudo apt install gparted
sudo gparted

Создание ФС

sudo mkfs.ext4 /dev/sdb1
sudo mkfs.btrfs /dev/sdb1
sudo mkfs.xfs /dev/sdb1
sudo mkfs.fat -F32 /dev/sdb1
