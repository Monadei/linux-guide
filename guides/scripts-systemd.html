systemd units

Свои сервисы.

Что это

Юнит — единица конфигурации: сервис, таймер, устройство.

Простой сервис

# /etc/systemd/system/myapp.service
[Unit]
Description=My App
After=network.target

[Service]
Type=simple
User=monadei
WorkingDirectory=/home/monadei/myapp
ExecStart=/usr/bin/python3 /home/monadei/myapp/main.py
Restart=on-failure

[Install]
WantedBy=multi-user.target

Активация

sudo systemctl daemon-reload
sudo systemctl enable --now myapp
sudo systemctl status myapp
journalctl -u myapp -f

Типы сервисов

  • simple — основной процесс
  • oneshot — разовая задача
  • forking — демон
  • notify — с уведомлением
