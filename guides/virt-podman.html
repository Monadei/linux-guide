Podman

Docker без демона.

Что это

Podman — альтернатива Docker от Red Hat. Без демона, rootless по умолчанию.

Установка

sudo apt install podman    # Ubuntu
sudo dnf install podman    # Fedora

Основы

podman run hello-world
podman ps
podman images
podman stop container_id

Отличия

  • Нет демона
  • Rootless по умолчанию
  • Команды совместимы: alias docker=podman

Systemd

podman generate systemd --new --name mycontainer > ~/.config/systemd/user/mycontainer.service
systemctl --user enable --now mycontainer
