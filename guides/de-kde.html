KDE Plasma — подробно

Самый гибкий DE.

Что это

KDE Plasma — максимально настраиваемый DE. Похож на Windows по логике. По умолчанию в Kubuntu, KDE Neon, openSUSE.

Установка

sudo apt install kde-plasma-desktop   # минимальный
sudo apt install kubuntu-desktop       # полный

KDE Store

Правый клик на рабочем столе → Добавить панель / Настроить. Все темы, иконки, виджеты — из встроенного магазина.

Полезные приложения

  • Dolphin — файловый менеджер
  • Konsole — терминал
  • Kate — редактор
  • Kdenlive — видеомонтаж
  • Krita — графика

Настройка через терминал

lookandfeeltool -l                       # список тем
lookandfeeltool -a org.kde.breeze.desktop  # применить
