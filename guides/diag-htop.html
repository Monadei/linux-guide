htop / btop

Мониторинг системы.

Установка

sudo apt install htop btop

htop

  • F1 — помощь
  • F3 — поиск
  • F4 — фильтр
  • F5 — дерево
  • F6 — сортировка
  • F9 — kill
  • F10 — выход

btop

Современный мониторинг с графиками. Просто запусти btop.
