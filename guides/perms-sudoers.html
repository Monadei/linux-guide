sudo и sudoers

Настройка прав sudo.

Как работает sudo

  1. Проверяет пользователя в /etc/sudoers
  2. Спрашивает его пароль
  3. Выполняет команду от root

Редактирование

sudo visudo

Только через visudo — проверяет синтаксис.

Примеры правил

monadei ALL=(ALL) ALL                    # с паролем
monadei ALL=(ALL) NOPASSWD: ALL          # без пароля
monadei ALL=(ALL) /usr/bin/apt           # только apt
%admins ALL=(ALL) ALL                    # группа

Добавить в группу sudo

# Debian/Ubuntu
sudo usermod -aG sudo monadei

# RHEL/Fedora/Arch
sudo usermod -aG wheel monadei

Проверка

sudo -l
