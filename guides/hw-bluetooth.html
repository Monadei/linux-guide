Bluetooth

Настройка Bluetooth.

Проверка

systemctl status bluetooth
bluetoothctl

Установка пакетов

sudo apt install bluez bluez-tools
sudo systemctl enable --now bluetooth

Подключение

bluetoothctl
  power on
  scan on
  pair XX:XX:XX:XX:XX:XX
  connect XX:XX:XX:XX:XX:XX
  trust XX:XX:XX:XX:XX:XX
