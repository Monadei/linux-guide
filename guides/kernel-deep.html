Ядро Linux — подробно

Что это, как работает, как обновлять.

Что такое ядро

Ядро — посредник между программами и железом. Управляет:

  • Процессором
  • Памятью
  • Дисками
  • Сетью
  • Устройствами

Версии ядра

  • Mainline — самая свежая, для разработки
  • Stable — стабильная
  • LTS — долгосрочная, 2-6 лет поддержки
  • Distro — ядро дистрибутива (с патчами)

Проверка версии

uname -r
uname -a
cat /proc/version

Типы ядер

  • generic — стандартное
  • low-latency — для аудио
  • RT — реального времени
  • hardened — безопасность
  • zen — для десктопа и игр

Обновление

# Ubuntu/Debian
sudo apt update && sudo apt upgrade

# Fedora
sudo dnf upgrade --refresh

# Arch
sudo pacman -Syu
