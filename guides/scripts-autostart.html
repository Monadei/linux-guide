Автозапуск

Программы при входе.

Способы

  • systemd — сервисы
  • .desktop — GUI-приложения
  • ~/.bashrc — shell

.desktop для GUI

# ~/.config/autostart/myapp.desktop
[Desktop Entry]
Type=Application
Name=My App
Exec=/home/monadei/myapp
Terminal=false
X-GNOME-Autostart-enabled=true

GNOME

Настройки → Приложения → Автозапуск

KDE

Системные настройки → Автозапуск

systemd (user)

systemctl --user enable myapp.service
