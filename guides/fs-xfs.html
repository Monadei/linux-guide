XFS

Для больших файлов и серверов.

Что это

XFS — ФС от SGI, стандарт в RHEL. Отлично работает с большими файлами и базами данных.

Плюсы и минусы

Плюсы: быстрая на больших файлах, до 8 ЭБ, онлайн-дефрагментация.

Минусы: нельзя уменьшить размер, нет снапшотов.

Создание

sudo mkfs.xfs /dev/sdb1
sudo mkfs.xfs -L DATA /dev/sdb1
sudo mkfs.xfs -f /dev/sdb1  # принудительно

Увеличение

sudo xfs_growfs /mnt/data
# Уменьшить НЕЛЬЗЯ

Проверка

sudo umount /dev/sdb1
sudo xfs_repair /dev/sdb1
sudo xfs_info /mnt/data
