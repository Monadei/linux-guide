Создание

sudo adduser monadei
sudo useradd -m -s /bin/bash -G sudo,wheel monadei
sudo passwd monadei

Изменение

sudo usermod -L monadei   # блокировать
sudo usermod -U monadei   # разблокировать
sudo usermod -aG docker monadei
sudo usermod -s /bin/zsh monadei

Удаление

sudo userdel monadei
sudo userdel -r monadei
