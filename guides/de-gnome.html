GNOME — подробно

Самый популярный DE в Linux.

Что это

GNOME — минималистичный DE с фокусом на задачи. По умолчанию в Ubuntu, Fedora, Debian.

Установка

sudo apt install gnome-shell gnome-tweaks gnome-shell-extensions

Расширения

  • AppIndicator — иконки в трее
  • Dash to Dock — док
  • Blur My Shell — размытие
  • Just Perfection — тонкая настройка
  • Clipboard Indicator — история буфера

Установка: extensions.gnome.org

Горячие клавиши

  • Super — Activities
  • Super+Tab — переключение окон
  • Super+1..9 — запуск приложений из дока
  • Super+←/→ — окно влево/вправо
  • Alt+F2 — запуск команд

Настройка через терминал

# Тема
gsettings set org.gnome.desktop.interface gtk-theme "Adwaita-dark"
gsettings set org.gnome.desktop.interface icon-theme "Papirus-Dark"
gsettings set org.gnome.desktop.interface cursor-theme "Bibata-Modern-Ice"

# Тёмный режим
gsettings set org.gnome.desktop.interface color-scheme "prefer-dark"
