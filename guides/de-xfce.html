Xfce — подробно

Лёгкий классический DE.

Что это

Xfce — лёгкий, стабильный, классический. Панель + меню + иконки. Идеален для старого железа.

Установка

sudo apt install xfce4 xfce4-goodies
# Или
sudo apt install xubuntu-desktop

Настройка

  • Settings → Appearance — темы
  • Settings → Window Manager — управление окнами
  • Settings → Panel — панель
  • Settings → Keyboard — горячие клавиши

Плагины панели

  • Whisker Menu — меню
  • PulseAudio Plugin — звук
  • System Load Monitor — нагрузка
  • Weather Update — погода
