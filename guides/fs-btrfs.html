Btrfs

Снапшоты, сжатие, subvolumes.

Что это

Btrfs — современная ФС от Oracle. Используется в Fedora, openSUSE, Synology.

Плюсы и минусы

Плюсы: снапшоты, сжатие zstd, subvolumes, RAID на уровне ФС, resize онлайн.

Минусы: RAID 5/6 проблематичен, сложнее ext4.

Создание

sudo mkfs.btrfs -L DATA /dev/sdb1
sudo mkfs.btrfs -d single -m raid1 /dev/sdb1 /dev/sdc1

Subvolumes

sudo btrfs subvolume create /mnt/data/documents
sudo btrfs subvolume list /mnt/data
sudo btrfs subvolume delete /mnt/data/documents

Снапшоты

sudo btrfs subvolume snapshot /mnt/data /mnt/snapshots/data-$(date +%Y%m%d)
sudo btrfs subvolume snapshot -r /mnt/data /mnt/snapshots/data-backup

Обслуживание

sudo btrfs filesystem usage /mnt/data
sudo btrfs check /dev/sdb1
sudo btrfs balance start -dusage=50 /mnt/data

Сжатие

sudo mount -o compress=zstd /dev/sdb1 /mnt/data
# В fstab:
UUID=xxx /mnt/data btrfs defaults,compress=zstd,noatime 0 2
