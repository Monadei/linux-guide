Частые вопросы

То, что спрашивают все, кто первый раз ставит Linux.

Как поставить Linux рядом с Windows?

Сожми раздел Windows через «Управление дисками», отключи Fast Startup, загрузись с флешки и выбери «Установить рядом с Windows». GRUB найдёт Windows автоматически. Подробнее — в гайде по установке.

Почему чёрный экран после установки?

Чаще всего — проблема с драйвером видеокарты. В меню GRUB нажми e, найди строку с linux, добавь nomodeset в конце. Система загрузится в базовом режиме, дальше ставь драйверы.

Как поставить драйвер NVIDIA?

На Ubuntu: sudo ubuntu-drivers autoinstall. На Fedora: sudo dnf install akmod-nvidia + RPM Fusion. На Arch: sudo pacman -S nvidia. Полный гайд — здесь.

Как запускать Windows-игры?

Steam + Proton — самый простой путь. Включи Proton в настройках Steam. Для не-Steam игр — Lutris или Heroic. Гайд — здесь.

Что такое Wayland и X11?

Это протоколы графики. Wayland — современный, X11 — старый. Fedora и Ubuntu уже на Wayland по умолчанию. Если что-то не работает — переключись на X11 через меню входа.

Как обновлять систему?

Ubuntu: sudo apt update && sudo apt upgrade. Fedora: sudo dnf upgrade. Arch: sudo pacman -Syu. Или просто через графический центр обновлений.

Где взять программы, которых нет в репозитории?

Flatpak, Snap, AppImage. Или добавь PPA (Ubuntu), COPR (Fedora), AUR (Arch). Всё есть в сравнении пакетных менеджеров.

Что делать, если не работает Wi-Fi?

Подключись по кабелю, установи драйверы: sudo apt install linux-firmware. Проверь, что не стоит проприетарный Broadcom: sudo apt install bcmwl-kernel-source.

Пропала Windows после установки Linux

Ничего не пропало — просто GRUB не видит её. Выполни sudo update-grub. Если не помогло — sudo os-prober и снова sudo update-grub.

Сколько RAM нужно для Linux?

Минимум: 512 МБ (antiX, Puppy). Комфортно: 2 ГБ (Xfce, LXQt). Современно: 4+ ГБ (GNOME, KDE). Для игр: 8+ ГБ.

Как узнать комплектующие?

Команда inxi -F покажет всё сразу. Или по отдельности: lscpu, free -h, lsblk, lspci. Подробнее — здесь.

Что выбрать — GNOME или KDE?

GNOME — минимализм, как macOS. KDE — гибкость, как Windows. Оба хороши. Попробуй оба на Live USB. Сравнение — здесь.
