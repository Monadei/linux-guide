Как узнать комплектующие

Что у тебя внутри компьютера — процессор, память, диск, видеокарта. Без разбора корпуса.

Самое простое: команда lscpu

Открой терминал (Ctrl+Alt+T) и введи:

lscpu

Покажет процессор: модель, ядра, частоту, архитектуру.

Память: free -h

free -h

Строка Mem: — оперативная память. total — сколько всего.

Диски: lsblk

lsblk

Дерево дисков и разделов. Показывает размер каждого.

Ещё подробнее:

df -h

Показывает, сколько места занято и свободно.

Видеокарта: lspci

lspci | grep -i vga

Покажет модель видеокарты — Intel, AMD или NVIDIA.

Для NVIDIA:

nvidia-smi

Всё сразу: inxi

Это лучший инструмент. Обычно не установлен, но ставится одной командой:

sudo apt install inxi

Потом:

inxi -F

Выдаст полную картину: модель ПК, процессор, память, диски, видеокарты, сеть, звук. Один экран — вся система.

Красиво: neofetch / fastfetch

sudo apt install neofetch
neofetch

Покажет логотип дистрибутива и краткую сводку: ОС, ядро, DE, процессор, память. Красиво для скриншота, полезно для форумов.

Современная альтернатива — fastfetch (быстрее):

sudo apt install fastfetch

Если что-то не установлено

Все команды выше, кроме lscpu, lsblk, lspci, free — могут требовать установки. Список базовых:

  • lscpu — часть util-linux, есть всегда
  • lsblk — там же
  • lspci — пакет pciutils
  • inxi — отдельно
  • neofetch / fastfetch — отдельно

Графический способ

Не хочешь терминал? Есть GUI-утилиты:

  • Hardinfo — sudo apt install hardinfo
  • CPU-G — sudo apt install cpu-g
  • GNOME Settings → About — базовые данные о системе

Для моего MacBook 2014

На старых маках Linux видит не всё идеально, но основные данные доступны:

sudo dmidecode -t system
sudo dmidecode -t memory

Покажет модель мака и сколько памяти распаяно.
