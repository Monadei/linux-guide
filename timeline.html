Таймлайн Linux

35 лет истории — от хобби-проекта студента до основы интернета.

1991 — Линус Торвальдс публикует ядро Linux 0.01
1992 — Linux становится свободным по лицензии GPL
1993 — Появляются Debian и Slackware — два старейших дистрибутива
1994 — Red Hat Linux. Первый коммерческий успех
1996 — Tux становится талисманом Linux
1999 — GNOME и KDE — начало эры десктопных окружений
2000 — Gentoo. Red Hat разделяется на RHEL и Fedora
2002 — Arch Linux
2003 — Fedora. CentOS
2004 — Ubuntu. Первый релиз — 4.10 Warty Warthog
2005 — openSUSE. Git создан Линусом
2006 — Linux Mint. Oracle Linux
2007 — Android на базе ядра Linux
2008 — Первый Android-телефон. Зорин OS
2010 — Qubes OS. Расцвет облаков на Linux
2011 — Manjaro. elementary OS. 76% серверов — Linux
2013 — Kali Linux. NixOS. SteamOS 1.0
2014 — MX Linux. Red Hat покупает CentOS
2015 — Solus. Clear Linux. Windows 10 включает WSL
2017 — Pop!_OS. PureOS. postmarketOS
2019 — EndeavourOS. Fedora CoreOS
2020 — Garuda. Red Hat закрывает CentOS Linux
2021 — AlmaLinux. Rocky Linux. CachyOS
2022 — Steam Deck. SteamOS 3.0 на Arch
2023 — blendOS. Rhino Linux
2024 — Wayland доминирует в Fedora, Ubuntu, KDE
2025 — NebiOS. KDE Linux. AerynOS. MacBook 2014 жив благодаря Mint
2026 — Ubuntu 26.04 LTS. Linux на 5%+ десктопов мира
