50 приложений для Linux

Что стоит поставить после установки системы.

Браузеры и интернет

  • Firefox (есть везде)
  • Chromium — открытый Chrome
  • Brave — блокировка рекламы
  • qBittorrent — торренты
  • Transmission — лёгкий торрент-клиент
  • Thunderbird — почта
  • Telegram Desktop
  • Discord (или Ripcord, WebCord)

Офис

  • LibreOffice — полный пакет
  • OnlyOffice — совместимость с MS Office
  • Obsidian — заметки
  • Joplin — заметки с шифрованием
  • Okular — PDF
  • Calibre — электронные книги

Медиа

  • VLC — видео всего форматов
  • mpv — минималистичный плеер
  • Audacious — музыка
  • Strawberry — музыка с библиотекой
  • OBS Studio — запись и стрим
  • Kdenlive — видеомонтаж
  • DaVinci Resolve — профессиональный видеомонтаж
  • HandBrake — конвертер видео

Графика

  • GIMP — растровая графика
  • Krita — рисование
  • Inkscape — вектор
  • Blender — 3D
  • Darktable — RAW-фото
  • Shotcut — простое видео

Разработка

  • VS Code — редактор
  • Neovim — редактор в терминале
  • Git + gitg или GitKraken
  • Docker / Podman
  • Postman / Insomnia — API
  • DBeaver — базы данных

Системные

  • Timeshift — бэкапы
  • GParted — разделы
  • htop / btop — процессы
  • BleachBit — очистка
  • Stacer — мониторинг
  • Timeshift — снапшоты

Игры

  • Steam
  • Lutris
  • Heroic Games Launcher
  • Bottles
  • MangoHud — FPS-оверлей

Утилиты

  • KeePassXC — пароли
  • Syncthing — синхронизация
  • Flameshot — скриншоты
  • CopyQ — буфер обмена
  • Albert / Ulauncher — лаунчер
  • Variety — обои

Коммуникация

  • Signal Desktop
  • Element — Matrix
  • Zoom
  • Slack

Установка всего сразу

sudo apt install firefox vlc gimp libreoffice htop git curl \
  timeshift gparted flameshot keepassxc qbittorrent transmission \
  obs-studio kdenlive okular calibre

Остальное — через Flatpak или официальные сайты.
