Основы Bash

Переменные, условия, циклы, функции — простыми словами.

Переменные

NAME="Артём"
echo "Привет, $NAME"
echo "Сегодня $(date)"

Условия

if [ -f /etc/passwd ]; then
  echo "Файл есть"
else
  echo "Файла нет"
fi

Циклы

for f in *.txt; do
  echo "Обрабатываю $f"
done

while read line; do
  echo "$line"
done < file.txt

Функции

greet() {
  echo "Привет, $1!"
}
greet "Артём"

Аргументы скрипта

# script.sh
echo "Первый аргумент: $1"
echo "Всего аргументов: $#"
echo "Все аргументы: $@"

Запуск: ./script.sh hello world

Проверки

[ -f файл ]    # файл существует
[ -d папка ]   # папка существует
[ -z "$VAR" ]  # переменная пуста
[ "$a" = "$b" ] # строки равны
[ "$a" -eq "$b" ] # числа равны

Полезные конструкции

# Проверка на root
if [ "$EUID" -ne 0 ]; then
  echo "Запусти от sudo"; exit 1
fi

# Значение по умолчанию
NAME=${1:-"гость"}

# Команда с проверкой
command -v git >/dev/null || sudo apt install git

Пример: бэкап

#!/bin/bash
SRC="$HOME/Documents"
DST="/mnt/backup/$(date +%Y-%m-%d)"
mkdir -p "$DST"
rsync -avh --delete "$SRC/" "$DST/"
echo "Готово: $DST"

Сохрани как backup.sh, потом:

chmod +x backup.sh
./backup.sh
