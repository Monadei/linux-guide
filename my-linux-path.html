Мой путь в Linux

От первой загрузки Live USB до создания этого сайта.

Начало: случайность

Году в 2022-м увидел на YouTube ролик про Ubuntu. Загорелся, скачал ISO, записал на флешку. Загрузился — понравилось. Потыкал час и выключил. Тогда не решился.

Первый опыт: WSL

Поставил WSL2 на Windows. Терминал Ubuntu прямо в Windows. Это было безопасно — если что, всегда можно было вернуться. Так я выучил ls, cd, apt, sudo. И понял, что терминал — это быстро и удобно.

Второй опыт: Live USB

Через полгода записал Ubuntu на флешку и загрузился без установки. Погонял час, посмотрел на GNOME, поигрался с настройками. Понравилось больше. Тогда купил второй SSD, поставил Ubuntu рядом с Windows.

Месяц с двумя системами

Первые недели прыгал туда-сюда. Windows для игр, Ubuntu для работы. Потом заметил, что в Windows захожу только для конкретных игр. Настроил Proton — игры заработали в Ubuntu. Перестал заходить в Windows совсем.

Снёс Windows

Через 4 месяца снёс Windows полностью. Осталась только Ubuntu. Оказалось — не страшно. Всё что нужно, работает.

MacBook 2014

Был старый MacBook, который лежал без дела. Apple перестала его поддерживать. Поставил Linux Mint с Cinnamon — работает как новый. Теперь это второй рабочий ноутбук.

Идея сайта

Когда я начинал, информации было много, но она была разбросана. Форум тут, статья там, видео ещё где-то. Хотелось один сайт, где всё понятно и по-русски. Так появился Linux Guide.

  • Linux Mint Cinnamon на MacBook Pro 2014
  • Этот сайт — 150+ страниц, 30 тем, куча фич
  • Учусь каждый день

Совет тем, кто начинает

Не спеши. Не нужно сносить Windows сразу. Поставь Linux рядом, попробуй. Найди свой ритм. И не бойся ломать — Live USB спасёт, chroot вернёт, форумы помогут.
