Ошибки новичков

Что не надо делать в Linux. Серьёзно.

1. rm -rf /

Удаляет всю систему. Не запускай никогда, даже в шутку. Одна опечатка в rm -rf /home/user → rm -rf / home/user = катастрофа.

2. chmod 777 везде

«Чтобы точно работало» — не работает. 777 = даёт всем полный доступ. Правильно: 644 для файлов, 755 для папок, 600 для приватных.

3. Работать от root постоянно

Одна ошибка — и система убита. Используй sudo только когда нужно.

4. Ставить .deb / .rpm с непроверенных сайтов

Только официальные сайты и репозитории. .deb — это не просто архив, он может исполнить произвольный код при установке.

5. Добавлять случайные PPA

PPA — это репозиторий от сторонних разработчиков. Один плохой PPA может сломать обновления. Проверяй, кому доверяешь.

6. Копировать команды из интернета не читая

Особенно с sudo. Особенно длинные. Особенно с | bash в конце.

7. Игнорировать обновления

Особенно безопасности. Раз в неделю хотя бы: sudo apt update && sudo apt upgrade.

8. Не делать бэкапы

Диск умрёт. Всегда. Не «если», а «когда». Timeshift + rsync — минимум.

9. Удалять пакеты «на глаз»

sudo apt autoremove может снести нужное. Читай, что удаляется, перед подтверждением.

10. Устанавливать Wayland-несовместимые драйверы

Если у тебя GNOME на Wayland и NVIDIA — проверь, что драйвер 495+. Старые не работают.

11. Ставить всё из Snap

Snap-пакеты запускаются дольше, занимают больше места, зависят от Canonical. Используй apt или Flatpak для большинства задач.

12. Паниковать при чёрном экране

Не паникуй. Live USB + chroot + восстановление GRUB — работает в 95% случаев.
