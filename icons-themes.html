Иконки и курсоры

Лучшие наборы для красивого рабочего стола.

Иконки

  • Papirus — самый популярный, огромная база. sudo apt install papirus-icon-theme
  • Numix — минимализм, плоский стиль. sudo apt install numix-icon-theme
  • Reversal — цветные, в том числе тёмные версии
  • WhiteSur — в стиле macOS Big Sur
  • Fluent — в стиле Windows 11
  • Materia — Google Material Design
  • Arc — минималистичный, серые
  • Yaru — стандартные Ubuntu
  • Adwaita — стандартные GNOME
  • Colloid — гибкий, много вариантов цвета

Курсоры

  • Bibata — современный, круглый. sudo apt install bibata-cursor-theme
  • Phinger — минималистичный, в стиле macOS
  • Adwaita — стандартный
  • WhiteSur — macOS-стиль
  • Lyra — нежный, пастельные оттенки
  • Quintom — минималистичный
  • aosp — в стиле Android

Установка

Из репозитория (простой путь):

sudo apt install papirus-icon-theme bibata-cursor-theme

Вручную — скачал архив, распаковал в ~/.icons/:

mkdir -p ~/.icons
cd ~/.icons
tar -xzf ~/Downloads/набор.tar.gz
# или
unzip ~/Downloads/набор.zip

Системно:

sudo tar -xzf набор.tar.gz -C /usr/share/icons/

Применение

GNOME: gnome-tweaks → Appearance → Icons / Cursors.

KDE: Параметры → Внешний вид → Иконки / Курсоры.

Xfce: Настройки → Внешний вид → Значки.

Вручную через gsettings:

gsettings set org.gnome.desktop.interface icon-theme 'Papirus-Dark'
gsettings set org.gnome.desktop.interface cursor-theme 'Bibata-Modern-Ice'

Смена цвета Papirus

Papirus Folders Color — утилита для смены цвета папок:

sudo apt install papirus-folders
papirus-folders -l --theme Papirus-Dark
papirus-folders -C blue --theme Papirus-Dark
