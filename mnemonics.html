Как запомнить команды

Расшифровки, которые помогают не путаться.

Базовые команды

ls
list — список файлов
cd
change directory — сменить папку
pwd
print working directory — где я
cp
copy — копировать
mv
move — переместить
rm
remove — удалить
mkdir
make directory — создать папку
rmdir
remove directory — удалить папку
man
manual — инструкция

С параметрами

ls -la
long (подробно) + all (включая скрытые)
rm -rf
recursive (рекурсивно) + force (без вопросов) — ОПАСНО
cp -r
recursive — копировать папку целиком
df -h
disk free + human-readable (в ГБ, МБ)
free -h
память + человекочитаемо
ps aux
process status + all users + user + no-terminal (всё)
du -sh
disk usage + summary + human

Пакетные менеджеры

apt
Advanced Package Tool
dnf
Dandified Yum — наследник yum
pacman
от «package manager» — почти как в игре
zypper
от «zip» — так называли установщики в SUSE

Прочее

sudo
superuser do — сделать от root
grep
от команды g/re/p в редакторе ed: global / regular expression / print
awk
по фамилиям создателей: Aхо, Wайнбергер, Kерниган
bash
Bourne Again SHell
GNU
GNU is Not Unix (рекурсивная расшифровка)
