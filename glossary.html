Словарь терминов

Всё, что нужно знать, чтобы понимать статьи про Linux.

Основы

Ядро (kernel)
Сердце системы. Управляет железом, памятью, процессами. У Linux — ядро Linux, у macOS — XNU, у Windows — NT.
Дистрибутив
Ядро + утилиты + пакетный менеджер + окружение. То, что ты ставишь на компьютер.
Live USB
Система, работающая прямо с флешки без установки. Полезна для знакомства и восстановления.

Интерфейс

DE (Desktop Environment)
Полноценное окружение: GNOME, KDE Plasma, Xfce, Cinnamon, MATE, Budgie, LXQt, Pantheon, DDE.
WM (Window Manager)
Управляет окнами. Может быть частью DE, а может быть самостоятельным: i3, Sway, Openbox, bspwm, dwm, Hyprland.
Тайловый WM
Окна не перекрываются, а делят экран. Популярен у разработчиков.
Wayland
Современный протокол графики. Заменяет X11. По умолчанию в Fedora, Ubuntu, KDE.
X11 / Xorg
Старый протокол графики. Всё ещё используется в некоторых дистрибутивах.

Пакеты

Пакет
Архив с программой и метаданными. Форматы: .deb (Debian/Ubuntu), .rpm (Fedora/RHEL/SUSE), .pkg.tar.zst (Arch).
Пакетный менеджер
Ставит и обновляет пакеты: apt (Debian), dnf (Fedora), pacman (Arch), zypper (SUSE), xbps (Void), apk (Alpine).
Репозиторий
Сервер с пакетами. Официальные и сторонние (PPA, COPR, AUR).
AUR
Arch User Repository. Пользовательские рецепты сборки пакетов для Arch.
Flatpak / Snap / AppImage
Универсальные форматы приложений, работающие во всех дистрибутивах.

Система

init
Первая программа, запускаемая ядром. Запускает всё остальное. Бывает systemd, OpenRC, runit, s6.
systemd
Самый популярный init. Управляет сервисами, логами (journald), таймерами. Спорный, но стандарт.
GRUB
Загрузчик. Показывает меню выбора ОС. Позволяет грузить Linux и Windows.
UEFI
Современный BIOS. Обязателен для Windows 11. Требует раздел EFI (FAT32).
Secure Boot
Защита UEFI от подмены загрузчика. Ubuntu, Fedora, RHEL её поддерживают. Остальные — нет.
root
Суперпользователь. Имеет полный доступ ко всему. Используется через sudo.
sudo
Выполнить команду от имени root. Требует пароль.

Диски

Раздел (partition)
Часть диска. Linux обычно ставится в отдельный раздел.
Файловая система
Как хранятся данные. ext4, Btrfs, XFS, ZFS, FAT32, NTFS.
Монтирование
Подключение раздела к папке. В Linux всё — файл, включая диски.
swap
Раздел или файл подкачки. Используется, когда не хватает RAM.
LUKS
Шифрование диска в Linux. Пароль спрашивают при каждой загрузке.
LVM
Менеджер логических томов. Позволяет менять размер разделов на лету.
Btrfs / ZFS
Современные ФС со снапшотами, контролем целостности, сжатием.

Безопасность

SELinux / AppArmor
Мандатный доступ. Ограничивает, что может делать программа. SELinux — в Fedora/RHEL, AppArmor — в Ubuntu/SUSE.
Firewall
Фильтр сетевого трафика. В Linux: iptables, nftables, ufw, firewalld.
VPN
Шифрованный туннель. WireGuard, OpenVPN.
Tor
Сеть анонимности. Используется в Tails, Whonix, Qubes.
