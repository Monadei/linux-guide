Как я ставил Ubuntu

Личный опыт. Что было просто, что сложно, что бы сделал иначе.

Подготовка

Скачал ISO Ubuntu 26.04 LTS с ubuntu.com. Проверил SHA256 — совпало. Записал на флешку 16 ГБ через Rufus на старом ноутбуке (был под рукой).

Первая попытка: dual-boot

Решил поставить рядом с Windows — на всякий случай. В управлении дисками сжал Windows-раздел, освободил 100 ГБ. Отключил Fast Startup в настройках электропитания. Загрузился с флешки через F12.

Установщик

Ubuntu 26.04 использует новый установщик на Flutter. Выбрал:

  • Язык — русский
  • Раскладка — русская + английская
  • Обновления — скачивать во время установки
  • Стороннее ПО — да (драйверы NVIDIA!)
  • Тип установки — «Установить рядом с Windows»

Проблема с NVIDIA

Первый запуск — чёрный экран после входа. Оказалось, драйвер NVIDIA 550 не подхватился на Wayland. Загрузка в recovery mode и:

sudo ubuntu-drivers autoinstall
sudo reboot

Помогло. Драйвер 550 встал, Wayland заработал, nvidia-smi показывает RTX 3050.

Первые настройки

  1. Обновил систему — 15 минут
  2. Поставил темы Aura-Glass + иконки Reversal-purple-dark
  3. GNOME Extensions: AppIndicator, Dash to Dock, Blur My Shell
  4. Firefox с логинами, Chrome для работы
  5. Steam + Proton — проверил пару игр, работают
  6. Timeshift — первый снапшот системы
  7. rsync бэкап важных данных на внешний диск

Что не сработало сразу

  • Принтер HP — поставил через hplip
  • Bluetooth-наушники — пришлось установить pulseaudio-module-bluetooth
  • Второй монитор с портретным режимом — не сразу настроил в GNOME
  • Сканер — через simple-scan

Что бы сделал иначе

  • Сразу создал бы отдельный раздел /home
  • Поставил бы timeshift до того, как что-то ломать
  • Изучил бы man и tldr раньше — они экономят кучу времени

Через месяц

Захожу в Windows раз в неделю — для одной специфичной программы. Всё остальное делаю в Ubuntu. Система работает стабильно, ничего не ломалось. Если ты ещё думаешь — ставь, не пожалеешь.
