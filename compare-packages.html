Сравнение пакетных менеджеров

Как ставить, обновлять и удалять пакеты в разных дистрибутивах.

Действиеapt (Debian)dnf (Fedora)pacman (Arch)zypper (SUSE)xbps (Void)apk (Alpine)
Обновить индексыapt updatednf check-updatepacman -Syzypper refreshxbps-install -Sapk update
Установитьapt install имяdnf install имяpacman -S имяzypper install имяxbps-install имяapk add имя
Удалитьapt remove имяdnf remove имяpacman -R имяzypper remove имяxbps-remove имяapk del имя
Обновить всёapt upgradednf upgradepacman -Syuzypper updatexbps-install -Suapk upgrade
Поискapt searchdnf searchpacman -Sszypper searchxbps-query -Rsapk search
Инфо о пакетеapt showdnf infopacman -Sizypper infoxbps-query -Rapk info
Очистить кешapt cleandnf clean allpacman -Sczypper cleanxbps-remove -Oapk cache clean
Формат пакета.deb.rpm.pkg.tar.zst.rpm.xbps.apk

Универсальные форматы

Работают во всех дистрибутивах, изолированы от системы:

  • Flatpak — flatpak install flathub org.имя.Приложения. Основной в Fedora, Mint, elementary.
  • Snap — snap install имя. Основной в Ubuntu.
  • AppImage — просто скачал файл и запустил. Ничего ставить не надо.

Что выбрать

  • Новичку — ничего не выбирать, пользоваться графическим центром приложений.
  • Debian/Ubuntu — apt + PPA + Flatpak.
  • Fedora — dnf + COPR + Flatpak.
  • Arch — pacman + AUR (через yay или paru).
  • openSUSE — zypper + OBS + Flatpak.
  • Универсально — Flatpak и AppImage везде.
