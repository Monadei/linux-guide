Первые 10 команд после установки

Что сделать сразу, чтобы система была готовой к работе.

1. Обновить всё

sudo apt updateDebian / Ubuntu / Mint
sudo apt upgrade -yУстановить обновления
sudo dnf upgrade --refreshFedora / AlmaLinux / Rocky
sudo pacman -SyuArch / Manjaro / EndeavourOS
sudo zypper dupopenSUSE Tumbleweed

2. Драйверы NVIDIA (если есть)

ubuntu-drivers devicesПосмотреть доступные драйверы
sudo ubuntu-drivers autoinstallУстановить автоматически
sudo rebootПерезагрузиться
nvidia-smiПроверить, что работает

3. Мультимедиа-кодеки

sudo apt install ubuntu-restricted-extrasUbuntu — кодеки, шрифты, Flash
sudo apt install mint-meta-codecsLinux Mint
sudo dnf install gstreamer1-plugins-{bad,good,ugly}Fedora

4. Базовый софт

sudo apt install git curl wget htop neofetch inxiИнструменты разработчика
sudo apt install gparted timeshiftРазделы + бэкапы
sudo apt install vlc gimp kdenliveМедиа

5. Flatpak

sudo apt install flatpakУстановить Flatpak
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepoДобавить Flathub

6. Шрифты

sudo apt install fonts-firacode fonts-jetbrains-monoШрифты для кода

7. Настроить swap

swapon --showПроверить swap
free -hПроверить RAM

8. Firewall

sudo ufw enableВключить (Ubuntu)
sudo systemctl enable firewalldFedora / RHEL

9. Timeshift — бэкапы

sudo timeshift --create --comments "first"Первый снапшот
sudo timeshift-launcherГрафическая настройка

10. Проверить систему

inxi -FПолная сводка о железе
neofetchКрасивая краткая сводка
journalctl -p 3 -xbОшибки с последней загрузки
