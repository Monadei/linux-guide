Docker и Podman

Контейнеры для разработки и развёртывания. Что выбрать и как начать.

Docker vs Podman

  • Docker — стандарт индустрии. Демон работает от root. Больше документации.
  • Podman — от Red Hat. Без демона, rootless по умолчанию. Более безопасен. Команды совместимы.

Для начала: если не знаешь — бери Docker. Если ценишь безопасность — Podman.

Установка Docker

sudo apt update
sudo apt install docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER

После добавления в группу — перелогинься. Проверка:

docker run hello-world

Установка Podman

sudo apt install podman

Проверка:

podman run hello-world

Основные команды

docker psЗапущенные контейнеры
docker ps -aВсе контейнеры
docker imagesСкачанные образы
docker run -it ubuntu bashЗапустить Ubuntu в контейнере
docker run -d -p 8080:80 nginxNginx на порту 8080
docker stop имяОстановить
docker rm имяУдалить контейнер
docker rmi образУдалить образ

Docker Compose

Для многосервисных приложений:

sudo apt install docker-compose-v2

Пример docker-compose.yml:

services:
  web:
    image: nginx
    ports:
      - "8080:80"
  db:
    image: postgres
    environment:
      POSTGRES_PASSWORD: secret

Запуск: docker compose up -d.

Полезные советы

  • Не запускай контейнеры от root без необходимости
  • Чисти старые образы: docker system prune -a
  • Логи: docker logs имя
  • Войти в запущенный контейнер: docker exec -it имя bash
