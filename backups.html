Бэкапы в Linux

Что, чем и как часто сохранять, чтобы не потерять данные.

Правило 3-2-1

  • 3 копии данных
  • 2 разных носителя
  • 1 копия вне дома

Timeshift — для системы

Снапшоты системы. Если что-то сломалось — откат в один клик.

sudo apt install timeshift

Настройка: выбери диск, расписание (ежедневно), хранить 5–10 снапшотов. Работает на ext4 и Btrfs.

Создать вручную:

sudo timeshift --create --comments "перед обновлением"

rsync — для данных

Универсальный инструмент. Копирует файлы в любую точку.

rsync -avh --progress ~/Documents /mnt/backup/

С удалением файлов, которых больше нет в источнике:

rsync -avh --delete ~/Documents /mnt/backup/

На удалённый сервер по SSH:

rsync -avh -e ssh ~/Documents user@server:/backup/

Borg — умные бэкапы

Дедупликация, шифрование, снапшоты.

sudo apt install borgbackup
borg init --encryption=repokey /mnt/backup/borg
borg create /mnt/backup/borg::first ~/Documents
borg list /mnt/backup/borg

Restic — современная альтернатива

sudo apt install restic
restic init --repo /mnt/backup/restic
restic -r /mnt/backup/restic backup ~/Documents
restic -r /mnt/backup/restic snapshots

Что бэкапить

  • Обязательно: ~/Documents, ~/Pictures, ~/Projects, ~/.ssh, ~/.gnupg
  • Полезно: список установленных пакетов: dpkg --get-selections > packages.txt
  • Не нужно: система (для неё Timeshift), кеши, ~/.cache

Что не делать

  • Не хранить единственный бэкап на том же диске, что и данные
  • Не бэкапить на NTFS-раздел, если это система (проблемы с правами)
  • Не забывать проверять бэкапы — попробуй восстановить хоть раз
