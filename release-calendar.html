Как обновляться

# Ubuntu / Debian
sudo apt update && sudo apt full-upgrade

# Fedora
sudo dnf upgrade --refresh

# Arch / Manjaro
sudo pacman -Syu

# openSUSE
sudo zypper dup

Совет

Для продакшена — LTS. Для экспериментов — rolling. Для дома — LTS с точками обновления безопасности. Не гонись за свежим — стабильность важнее.
