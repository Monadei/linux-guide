Kali — что после установки

Что делать сразу после установки.

Важно

Kali — не для повседневного использования. Ставь только в виртуалке или на отдельный диск.

1. Обновление

sudo apt update && sudo apt full-upgrade -y

2. Смена пользователя

useradd -m -G sudo -s /bin/bash monadei
passwd monadei

3. Что установлено

  • nmap, Metasploit, Burp Suite, Wireshark
  • John, Hashcat, Hydra
  • Aircrack-ng, Reaver
  • Maltego, BeEF, SQLMap

4. Дополнительные инструменты

sudo apt install kali-linux-default
sudo apt install kali-linux-large
sudo apt install kali-linux-everything
