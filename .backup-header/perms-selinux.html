SELinux

Мандатный доступ в Fedora/RHEL.

Что это

SELinux — мандатный доступ. Даже если программу взломают, она не сможет делать то, что не разрешено.

Режимы

  • Enforcing — блокирует
  • Permissive — только логирует
  • Disabled — выключен

Проверка

getenforce
sestatus

Смена режима

sudo setenforce 0   # Permissive
sudo setenforce 1   # Enforcing
# Постоянно — /etc/selinux/config

Контексты

ls -Z /var/www/
sudo chcon -t httpd_sys_content_t /var/www/html/file.html
sudo restorecon -Rv /var/www/

Логи

sudo ausearch -m avc -ts recent
sudo sealert -a /var/log/audit/audit.log
