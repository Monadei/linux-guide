Как сделать скриншот в Ubuntu

  • Весь экран: Print Screen
  • Окно: Alt + Print Screen
  • Область: Shift + Print Screen
  • Сохранить сразу в файл: Ctrl + Print Screen → сохранит в ~/Pictures/Screenshots/

Скриншоты автоматически сохраняются в ~/Pictures/Screenshots/ с именами вида Screenshot from 2026-09-20 15-30-45.png.

Как вставить в сайт

  1. Сделай скриншот — он сохранится в ~/Pictures/Screenshots/
  2. Скопируй файл: 
    cp ~/Pictures/Screenshots/*.png ~/data/linux-guide/img/
  3. Переименуй для удобства: 
    mv ~/data/linux-guide/img/"Screenshot from..."*.png ~/data/linux-guide/img/desktop.png
  4. В файле screenshots.html замени блок <div class="screenshot-slot">...</div> на: 
    <div class="screenshot-frame">
  <img src="img/desktop.png" alt="Мой рабочий стол в Ubuntu">
</div>

Полезные утилиты для скриншотов

  • GNOME Screenshot — встроен, простой
  • Flameshot — редактор + скриншот: sudo apt install flameshot
  • Shutter — мощный, но давно не обновляется
  • Spectacle — для KDE
  • scrot — для терминала: scrot screenshot.png
