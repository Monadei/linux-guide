Генератор nginx.conf

Выбери опции — получи готовый конфиг для nginx.

Выбери опции и нажми «Сгенерировать»

Как применить

  1. Сохрани конфиг в /etc/nginx/sites-available/example.com
  2. Создай симлинк: sudo ln -s /etc/nginx/sites-available/example.com /etc/nginx/sites-enabled/
  3. Проверь: sudo nginx -t
  4. Перезагрузи: sudo systemctl reload nginx
  5. Для HTTPS — сначала получи сертификат: sudo certbot --nginx -d example.com
