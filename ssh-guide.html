SSH и ключи

Как подключиться к удалённому серверу и не париться.

Что такое SSH

Secure Shell — протокол для подключения к удалённым машинам. Весь трафик шифруется. Используется для:

  • Подключения к серверам
  • GitHub/GitLab (для git push/pull)
  • Передачи файлов через scp/rsync
  • Туннелирования портов

Подключение по паролю

ssh user@server.com
ssh user@192.168.1.10
ssh user@server.com -p 2222

SSH-ключи — безопаснее пароля

Идея: есть приватный ключ (секрет) и публичный ключ (можно показывать). Сервер знает твой публичный, ты доказываешь владение приватным — без пароля.

Генерация ключа

ssh-keygen -t ed25519 -C "monadei@ubuntu"
  • -t ed25519 — современный алгоритм, короче и быстрее RSA
  • -C — комментарий (обычно email или имя хоста)
  • Ключ сохранится в ~/.ssh/id_ed25519 и ~/.ssh/id_ed25519.pub
  • Passphrase — необязательна, но если диск украдут — файл под паролем

Копирование ключа на сервер

ssh-copy-id user@server.com

Публичный ключ добавится в ~/.ssh/authorized_keys на сервере. Всё, теперь можно без пароля.

Для GitHub

cat ~/.ssh/id_ed25519.pub

Скопируй вывод, зайди на GitHub → Settings → SSH and GPG keys → New SSH key.

Проверка:

ssh -T git@github.com

~/.ssh/config

Чтобы не вводить длинные команды, создай файл:

Host myserver
    HostName 192.168.1.10
    User monadei
    Port 2222
    IdentityFile ~/.ssh/id_ed25519

Теперь вместо ssh user@192.168.1.10 -p 2222:

ssh myserver

Права на файлы

SSH строго следит за правами:

chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub
chmod 600 ~/.ssh/config
chmod 600 ~/.ssh/authorized_keys

Если права неверные — SSH откажется работать.

Агент SSH

Чтобы не вводить passphrase каждый раз:

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

Добавить в ~/.bashrc или ~/.zshrc, чтобы запускался автоматически.

Передача файлов

scp file.txt user@server:/path/
scp user@server:/path/file.txt .
rsync -avh --progress ~/Documents/ user@server:/backup/

Туннелирование

Пробросить порт:

ssh -L 8080:localhost:80 user@server

Теперь localhost:8080 на твоей машине — это порт 80 на сервере.

Управление сервером SSH

sudo systemctl status ssh
sudo systemctl restart ssh
sudo systemctl stop ssh

Конфиг: /etc/ssh/sshd_config. После правок:

sudo systemctl reload ssh

Безопасность

  • Отключи вход по паролю: PasswordAuthentication no
  • Отключи root: PermitRootLogin no
  • Смени порт: Port 2222 (не панацея, но меньше ботов
  • Установи fail2ban — блокирует перебор паролей
  • Используй только ключи ed25519 или RSA 4096
  • Храни приватный ключ с passphrase
