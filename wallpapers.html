Обои для Linux

Где брать, какие ставить, чем управлять.

Лучшие источники

  • Unsplash — бесплатные фото, огромная база
  • Wallhaven — лучший сайт для обоев, теги, разрешения
  • Pexels — качественные фото
  • aesthetic-wallpapers — красивые минималистичные обои в GitHub
  • dwt1/wallpapers — коллекция от DistroTube

Встроенные обои

Все дистрибутивы идут с набором обоев в /usr/share/backgrounds/. Посмотреть:

ls /usr/share/backgrounds/

Скопировать понравившиеся:

cp /usr/share/backgrounds/понравилось.jpg ~/Pictures/

Сменщики обоев

  • Variety — автоматическая смена обоев из разных источников
  • HydraPaper — разные обои для каждого монитора
  • plasma-wallpaper — для KDE
  • Wallpaper Engine — через kde-plasma-wallpaper-engine

Установка Variety:

sudo apt install variety

Умеет: менять обои по расписанию, скачивать с Wallhaven / Unsplash / Bing, эффекты (размытие, оттенки).

Живые обои

  • Plasma — встроенная поддержка видео и веб-страниц как обоев
  • mpvpaper — видео на фоне рабочего стола (Wayland/X11)
  • Hyprpaper — для Hyprland
  • swaybg — для Sway
  • komorebi — анимированные обои с эффектами

Разрешение экрана

Проверь своё:

xrandr | grep '*'

На Wayland:

wlr-randr

Ищи обои в этом разрешении или больше (браузер/DE сам масштабирует).

Генераторы обоев

  • pattern.monster — паттерны
  • Subtle Patterns — фоны
  • SVG Backgrounds — векторные

Или сгенерируй свои:

sudo apt install inkscape
# Или используй GIMP

Оптимизация

  • PNG для минималистичных обоев (лучше сжимается без потерь)
  • JPG для фото (меньше размер)
  • WebP — современный, поддерживается большинством DE
  • Не ставь обои больше 4K — лишняя нагрузка на GPU
