Файловая система изнутри

Как Linux хранит файлы и почему это по-другому, чем в Windows.

Всё — файл

В Linux даже устройства — файлы. Клавиатура — файл /dev/input/event0. Диск — /dev/sda. Процессы — папка /proc/1234. Это философия Unix.

Права доступа

-rwxr-xr-x 1 monadei monadei 4096 Sep 19 file.txt
  • - — тип (файл, папка — d, ссылка — l)
  • rwx — права владельца (чтение, запись, выполнение)
  • r-x — права группы
  • r-x — права остальных
  • monadei monadei — владелец и группа

Числовая запись прав

  • r = 4, w = 2, x = 1
  • chmod 755 файл = rwxr-xr-x (обычно для исполняемых)
  • chmod 644 файл = rw-r--r-- (обычно для обычных файлов)
  • chmod 600 файл = rw------- (приватные, например ключи SSH)
  • chmod 700 папка = rwx------ (приватная папка)

Смена владельца

sudo chown monadei:monadei файл

Жёсткие и мягкие ссылки

Мягкая (symlink) — как ярлык. Указывает на путь:

ln -s /path/to/original link

Жёсткая — то же самое содержимое, но другое имя:

ln /path/to/original link

Жёсткие ссылки работают только в пределах одной файловой системы.

inode

Каждый файл имеет inode — запись, где хранятся метаданные (права, владелец, размер, дата). Имя файла — это ссылка на inode. Посмотреть:

ls -i файл

Файловые системы

  • ext4 — стандарт для Linux, надёжная, проверенная
  • Btrfs — современная, снапшоты, сжатие
  • XFS — для больших серверов
  • ZFS — мощная, для NAS
  • F2FS — для SSD и флешек
  • NTFS — Windows, монтируется через ntfs-3g
  • FAT32 — старый, для EFI-раздела

Монтирование

В Linux нет «дисков C:». Всё — часть единого дерева. Подключить диск:

sudo mkdir /mnt/mydisk
sudo mount /dev/sdb1 /mnt/mydisk

Отмонтировать:

sudo umount /mnt/mydisk

Автомонтирование при загрузке — через /etc/fstab.

Проверить место

df -h        # все ФС и место
du -sh ~     # размер домашней папки
