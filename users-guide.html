Пользователи и группы

Кто есть кто и как ими управлять.

Пользователи в системе

cat /etc/passwd   # все пользователи
cat /etc/shadow   # хеши паролей (только root)
w                 # кто сейчас в системе
who               # то же
last              # история входов
id                # мой UID, GID, группы

Формат /etc/passwd

monadei:x:1000:1000:Артём:/home/monadei:/bin/bash
  • monadei — имя
  • x — пароль в /etc/shadow
  • 1000 — UID
  • 1000 — GID основной группы
  • Артём — комментарий (имя)
  • /home/monadei — домашняя папка
  • /bin/bash — оболочка

UID

  • 0 — root
  • 1–999 — системные пользователи (демоны)
  • 1000+ — обычные пользователи

Создание пользователя

sudo useradd -m -s /bin/bash -c "Артём" monadei
sudo passwd monadei
sudo usermod -aG sudo monadei

Проще:

sudo adduser monadei

Интерактивно спросит пароль, имя, подтверждение.

Удаление

sudo userdel monadei
sudo userdel -r monadei   # с домашней папкой

Изменение

sudo usermod -c "Новое имя" monadei
sudo usermod -s /bin/zsh monadei
sudo usermod -d /home/newhome -m monadei  # сменить домашнюю
sudo usermod -L monadei  # заблокировать
sudo usermod -U monadei  # разблокировать

Группы

cat /etc/group   # все группы
groups monadei   # группы пользователя

Создать:

sudo groupadd developers

Добавить в группу:

sudo usermod -aG developers monadei

Важно: -aG, а не -G. Без -a пользователь будет удалён из всех остальных групп.

Удалить из группы — вручную через /etc/group или:

sudo deluser monadei developers

Важные группы

  • sudo / wheel — права root через sudo
  • docker — использовать Docker без sudo
  • libvirt — управлять виртуалками
  • vboxusers — USB в VirtualBox
  • video — доступ к видеокарте
  • audio — доступ к звуку
  • plugdev — USB-устройства
  • sudo (Debian) / wheel (RHEL) — админы

Смена пароля

passwd              # свой
sudo passwd monadei # чужой
sudo passwd -l monadei  # заблокировать
sudo passwd -u monadei  # разблокировать

Переключение пользователя

su monadei          # переключиться
su - monadei        # с полной средой
sudo -u monadei команда  # выполнить от имени
sudo -i             # root-shell

Sudo без пароля

sudo visudo

Добавить в конец:

monadei ALL=(ALL) NOPASSWD: ALL

Не рекомендуется, но удобно на личном ПК.

Автологин

GNOME: Настройки → Пользователи → Вход без пароля.

Вручную в GDM: /etc/gdm3/custom.conf:

[daemon]
AutomaticLoginEnable=true
AutomaticLogin=monadei

Скрытые пользователи

Системные пользователи есть почти у каждой программы: www-data для веб-сервера, mysql, systemd-network и т. д. Они без пароля, с оболочкой /usr/sbin/nologin или /bin/false.
