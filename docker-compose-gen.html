Генератор docker-compose.yml

Выбери сервисы — получи готовый docker-compose.yml.

Отметь сервисы и нажми «Сгенерировать»

Как использовать

  1. Сохрани в файл docker-compose.yml
  2. Запусти: docker compose up -d
  3. Посмотреть логи: docker compose logs -f
  4. Остановить: docker compose down
  5. Обновить образы: docker compose pull && docker compose up -d
⚠ Важно: замени change_me_please на настоящие пароли. И не коммить docker-compose.yml с паролями в git.
